## Q1 · Is the SQLCipher connection a strict singleton?

**Yes, and structurally — not by convention.** Three separate mechanisms:

1. **One process, one connection.** `KhataDb.open()` returns the existing
   instance for the same file, shares a single in-flight future between racing
   callers, and *refuses* a second file. `readPool` must be `0`, or the open
   fails (not an `assert` — release builds refuse too). A read pool would spawn
   extra isolates, each with its own SQLCipher connection and its own key
   derivation.
2. **One key derivation per process.** The key is attached in `setup:`, which
   runs inside the database isolate on the raw connection before any other
   statement. SQLCipher then holds the derived key in memory; the KDF runs once
   per process, not once per query and not once per screen.
3. **A published, tested contract.** `tool/data_layer_verify.dart` stage 3
   asserts: two concurrent `open()` calls return the *identical* instance; a
   third call while the first is live is also the same instance; a second file
   is refused; `readPool > 0` is refused; a *failed* open does not poison later
   attempts; and the database can be reopened after `close()`.

| where | what it guarantees |

## Q2 · Will offline writes merge without losing anything?

The short version: **ordering is decided by a stamp that carries its own reason**
(`(milliseconds, counter, node id)`, encoded fixed-width so text order *is*
causal order), and **every losing value is written to `conflict_log`** so it can
be reviewed and reversed. A CRDT cannot keep two values in one column; keeping
the loser *beside* the winner, with a review path, is the honest version of
"no data loss" — and it is what the code does.

| where | what it guarantees |
| --- | --- |
| `lib/core/crdt/hlc.dart:102` | The 57-character fixed-width wire form. Every field zero-padded ⇒ SQLite's ordinary BINARY collation orders stamps **exactly** as causal time orders them: no custom collation, no parsing during a delta scan, no index but a plain TEXT one. |
| `lib/core/crdt/hlc.dart:165` | Order is `(physicalMs, counter, nodeId)`. The node id in the key is what makes two writes in the same millisecond decidable with no server and no "who arrived first locally". |
| `lib/core/crdt/hlc.dart:235` | A peer whose clock is far ahead has its stamp clamped for *local advancement* (its own row keeps its stamp). One broken phone cannot drag the logical clock into the future for everyone. |
| `lib/core/crdt/hlc.dart:334` | Counter overflow rolls to the next millisecond instead of wrapping. |
| `lib/core/crdt/hlc_service.dart:61` | Logical time is persisted every 64 writes (and on pause/lock/shutdown). A crash can cost at most 64 ticks of counter space — never monotonicity. |
| `lib/core/crdt/hlc_service.dart:93` | A local edit advances the row's own stamp (`rev` grows with the HLC) — [CrdtStamp.bump]. |
| `lib/core/crdt/hlc_service.dart:107` | After applying a peer batch, the clock is advanced past everything seen, so the next local write orders after the remote work. |
| `lib/core/crdt/stamp.dart:37` | A stamp compares on the HLC **only**. `rev` is a consistency check for a single writer and is deliberately excluded from ordering. |
| `lib/core/crdt/stamp.dart:186` | Canonical JSON: keys sorted, integers only (a double is rejected, not silently rounded). Two devices compare payloads by string equality. |
| `lib/core/crdt/lww.dart:247` | The whole resolver, in one line: one comparison, no negotiation, no dependence on arrival order. |
| `lib/core/crdt/lww.dart:265` | The one genuinely undecidable case — one writer, one logical instant, two payloads. The local copy is kept and the anomaly is **blocking**: the sync layer stops and asks rather than inventing an answer. |
| `lib/core/crdt/lww.dart:292` | A restored/rolled-back replica looks like this. Reported as a **non-blocking** anomaly ("ask this peer for a fresh snapshot"): the merge still loses nothing, and blocking would strand a shopkeeper who merely restored their phone from a backup. |
| `lib/core/crdt/lww.dart:332` | Batch merge is a fold; order-independence is a property of `merge`, proven by 800 randomised interleavings in `tool/crdt_verify.dart` (which also asserts the conflict ledger is order-independent). |
| `lib/data/db/dao/base_dao.dart:367` | Merge receipts are **content-addressed**: the id names the conflict, not the recording device, so the same disagreement cannot be filed twice from either sync direction or on any number of replays. |
| `lib/data/db/dao/base_dao.dart:230` | An edit carrying a stamp the device no longer holds is refused (`CRDT-STALE`) instead of silently overwriting a peer's newer work. |
| `lib/data/repositories/order_book.dart:191` | The gate: run the work in a transaction, re-read the integrity findings **inside** it (same connection sees uncommitted rows), throw `GATE-2` if anything critical appeared ⇒ drift rolls the write back. |
| `lib/data/repositories/order_book.dart:643` | Undo picks its mechanism from the ledger state: period open → void; period locked → reversal dated the first day the ledger will accept a posting. |

# 1 · The singleton connection (SQLCipher key derivation happens once)

Answer to your first question. Read these four files in this order; the annotations table above points at the exact lines.

## `lib/data/db/database.dart` — 596 lines

```dart
/// KhataPro · the database, as a strict singleton.
///
/// ## Why "strict singleton" is a correctness requirement, not a style choice
///
/// The brief is explicit: repeatedly opening and closing the connection must not
/// happen. Three separate costs make that true here:
///
///   1. **Key work.** Every open walks the key chain: read `key_material`,
///      unwrap the DEK through the keystore (a Keystore round-trip — on Android
///      a `KeyStore.getKey` can take tens of milliseconds), then attach the raw
///      key to the connection. SQLCipher's own PBKDF2 is *not* paid here because
///      the key is passed raw (see `sqlcipher_key.dart`) — but the keystore hop
///      alone is reason enough.
///   2. **Page cache.** 16 MiB of decrypted pages, warmed by the first queries
///      after open. Re-opening discards it, and every re-read pays a SQLCipher
///      page decrypt again.
///   3. **Prepared statements.** The hot paths' statements are prepared once and
///      cached (`cachePreparedStatements: true`). A new connection re-prepares
///      and re-plans all of them.
///
/// `NativeDatabase.createInBackground(..., readPool: 0)` is used **because it
/// means exactly one connection**: the connection lives in a background isolate,
/// the main isolate talks to it over a port, and there is no pool to grow. A
/// non-zero `readPool` spawns extra isolates that each need their own SQLCipher
/// key attached. It is therefore pinned to 0 in [KhataDb.open] and a request
/// asking for more is refused in release builds, not just asserted.
///
/// ## Two isolates, one object graph — and why that shapes this file
///
/// `setup:` runs **inside the database isolate**. `beforeOpen` and every DAO run
/// in the **main isolate**, sending statements across the port. So:
///
///   · `setup:` may only touch the raw connection it is handed (that is where the
///     key is attached — it must be the first statement on that connection).
///   · `beforeOpen` may only use drift statements (`customStatement`,
///     `customSelect`); it must never reach for a raw `sqlite3.Database`, and it
///     *can* safely assign to fields on this object, because this object lives in
///     the main isolate with it. That is how diagnostics get out of the boot
///     sequence without a custom port protocol.
///
/// ## Lifecycle
///
/// ```
///   KhataDb.open(request)  →  KhataDb.instance  →  …  →  KhataDb.close()
/// ```
///
/// `open` is idempotent for the same file: a second call while the first is in
/// flight awaits the same future rather than racing. Opening a *different* file
/// while one is open throws, because two live databases means two writers and,
/// in a ledger, two truths.
library;

import 'dart:async';
import 'dart:io';

import 'package:drift/drift.dart';
import 'package:drift/native.dart';

import '../../core/crdt/hlc_service.dart';
import '../../core/errors/khata_exception.dart';
import '../../core/security/sqlcipher_key.dart';

    required this.databaseFile,
    required this.key,
    required this.nodeId,
    required this.platform,
    required this.appVersion,
    required this.assetLoader,
    this.requireEncryption = true,
    this.readPool = 0,
    this.hlcPersistence,
  });

  final File databaseFile;

  /// The DEK, already unwrapped. Never logged, never persisted in this form.
  final SqlCipherKey key;

  /// This device's UUIDv7 (`nodes.node_id`) — the CRDT's final tie-breaker.
  final String nodeId;

  /// `android` | `ios` | `macos` | `windows` | `linux` (the CHECK in
  /// `nodes.platform`).
  final String platform;

  final String appVersion;

  /// Where `assets/sql/**` comes from: `rootBundle` on device, the filesystem in

  final SqlAssetLoader assetLoader;

  final bool requireEncryption;

/// A critical/warning row from `v_integrity_report`.
final class IntegrityFinding {
  const IntegrityFinding({
    required this.severity,
    required this.kind,
    required this.detail,
    this.entityId,
  });

  /// **1 = critical, 2 = warning** — the convention `008_integrity.sql`
  /// documents at the top of its file, and the one `tool/verify_schema.sh`
  /// uses (`rows where severity = 1` are the critical ones). Getting this
  /// backwards means either ignoring a broken ledger or blocking a healthy one,
  /// so it is asserted in test/data/integrity_severity_test.dart rather than
  /// left to a comment.
  final int severity;
  final String kind;
  final String detail;
  final String? entityId;

  bool get isCritical => severity == 1;

  static IntegrityFinding fromRow(QueryRow row) => IntegrityFinding(
        severity: row.read<int>('severity'),
        kind: row.read<String>('kind'),
        detail: row.read<String>('detail'),
        entityId: row.read<String?>('entity_id'),
      );

  @override
  String toString() => '${isCritical ? 'CRITICAL' : 'warning'} $kind: $detail';
}

/// The drift handle: a `GeneratedDatabase` subclass **without** generated table
/// classes. The schema is owned by the `.sql` assets (45 tables, 18 views, 69
/// indexes, 33 triggers — proven by `tool/verify_schema.sh` and 35 SQL contract
/// tests); drift supplies the executor, transactions and statement plumbing.
final class KhataDatabase extends GeneratedDatabase {
  KhataDatabase(super.executor, {
    required this.assetLoader,
    required this.nodeId,
    required this.requireEncryption,
  });

  final SqlAssetLoader assetLoader;
  final String nodeId;
  final bool requireEncryption;

  /// No generated tables, deliberately: drift's schema tooling would otherwise
  /// try to reconcile generated Dart tables with the SQL-defined schema and
  /// report every view, index and trigger as unknown. docs/DB_SCHEMA.md is the
  /// contract that replaces drift codegen, and `tool/verify_schema.sh` counts
  /// the real objects at boot.
  ///
  /// `allSchemaEntities` intentionally inherits its default (`allTables`), so
  /// there is one empty list rather than two that could disagree.
  @override
  Iterable<TableInfo<Table, dynamic>> get allTables =>
      const <TableInfo<Table, dynamic>>[];

  @override
  int get schemaVersion => kLatestSchemaVersion;

  /// The last HLC emitted by this process. Initialised in the constructor so it
  /// exists for DAOs immediately; `beforeOpen` restores persisted logical time
  /// into it before the first user query.
  late final HlcService hlc = HlcService(
    nodeId: nodeId,
    persistence: hlcPersistence ?? DriftHlcPersistence(this),
  );

  /// Injectable for tests.
  HlcPersistence? hlcPersistence;

  /// Filled during `beforeOpen` — see the class docs on isolates.
  final BootDiagnostics diagnostics = BootDiagnostics();

  /// Set once `beforeOpen` has completed. Guarded so a DAO that somehow runs
  /// earlier fails with an explanation rather than a confusing SQL error.
  bool get isReady => _ready;
  bool _ready = false;

  @override
  MigrationStrategy get migration => MigrationStrategy(
        onCreate: (Migrator m) async {
          // Intentionally empty. Table creation belongs to the SQL assets, not
          // to drift codegen — a schema defined twice eventually disagrees with
          // itself. The migration runner creates everything, including on a
          // brand-new file.
        },
        onUpgrade: (Migrator m, int from, int to) async {
          // Same reasoning: the runner owns this. See migration_runner.dart.
        },
        beforeOpen: (OpeningDetails details) async {
          // ── 0 · Which SQLite are we? A build without SQLCipher ignores
          // `PRAGMA key` silently, so this is checked before anything else and
          // is fatal when encryption was requested.
          final cipherRows = await customSelect('PRAGMA cipher_version').get();
          final cipherVersion = cipherRows.isEmpty
              ? null
              : cipherRows.first.data.values.first?.toString();
          diagnostics.cipherVersion =
              (cipherVersion == null || cipherVersion.isEmpty) ? null : cipherVersion;
          diagnostics.encryptionMode = diagnostics.cipherVersion == null
              ? EncryptionMode.none
              : EncryptionMode.sqlcipher;
          if (requireEncryption && diagnostics.encryptionMode == EncryptionMode.none) {
            throw EncryptionUnavailable(
              'this build linked a SQLite without SQLCipher, so the database '
              'would be written UNENCRYPTED. Enable SQLCipher in pubspec.yaml '
              '(hooks: user_defines: sqlite3: source: sqlcipher) and rebuild.',
            );
          }

          // ── 1 · Session pragmas, on every open, before any read or write.
          await customStatement(
              await assetLoader.load('assets/sql/ops/open_pragmas.sql'));

          // ── 2 · Migrations: verbatim SQL, one transaction per file. This runs
          // before the wreckage check because the check itself needs
          // `session_flags`, which does not exist on a brand-new file.
          diagnostics.migration = await _runMigrations();

          // ── 3 · Dirty-open detection. `dirty_open` is set below, once the boot
          // has succeeded, and cleared on a clean close — so finding it set means
          // the previous run died while the database was live.
          final dirty = await _sessionFlag('dirty_open') == '1';
          if (dirty) {
            diagnostics.notes.add(
              'DIRTY_OPEN: the previous run did not close cleanly; running '
              'quick_check and re-deriving the balance cache',
            );
            diagnostics.quickCheckErrors = await _quickCheck();
            await customStatement('BEGIN IMMEDIATE');
            await customStatement(
                await assetLoader.load('assets/sql/ops/rebuild_caches.sql'));
            await customStatement('COMMIT');
          }
          await _setSessionFlag('dirty_open', '1');

          // ── 4 · Logical time, restored before the first write can happen.
          await hlc.load();

          // ── 5 · Expensive statistics work only when the plan cache is cold.
          if (details.wasCreated || dirty) {
            await customStatement('PRAGMA optimize');
          }

          // ── 6 · Read the audited integrity report so the app knows up front
          // whether it may trust its own numbers (see OrderBook.commitChecked).
          diagnostics.integrity = await integrityReport();
          _ready = true;
        },
      );

  /// Applies pending migrations through the same statements drift uses, so the
  /// transaction boundaries are drift's and a failure rolls back cleanly.
  Future<MigrationOutcome> _runMigrations() async {
    final runner = SqlMigrationRunner(loader: assetLoader);
    final started = DateTime.now();

    // The runner reads `schema_meta` through drift here, then applies files.
    final versionRows =
        await customSelect("SELECT value FROM schema_meta WHERE key = 'schema_version'")
            .get()
            .catchError((Object _) => <QueryRow>[]);
    final from = versionRows.isEmpty
        ? 0
        : int.tryParse(versionRows.first.read<String>('value')) ?? 0;

    // Before applying anything: confirm that already-applied files are
    // unchanged, and that no shipped file is unregistered.
    await runner.verifyShippedSet();
    await runner.verifyAppliedChecksums({
      for (final entry in SqlMigrationRunner.knownMigrations.entries)
        if (entry.key <= from) entry.value: await _recordedChecksum(entry.value),
    }..removeWhere((_, checksum) => checksum.isEmpty));

    final applied = <String>[];
    for (final migration in await runner.pendingMigrations(from)) {
      final sql = await assetLoader.load(migration.assetPath);
      await customStatement('BEGIN IMMEDIATE');
      try {
        await customStatement(sql);
        await customStatement(
          "INSERT OR REPLACE INTO schema_meta (key, value, updated_at) VALUES "
          "('migration.${migration.fileName}.sha256', '${migration.checksum}', "
          '${DateTime.now().millisecondsSinceEpoch})',
        );
        await customStatement(
          "INSERT OR REPLACE INTO schema_meta (key, value, updated_at) VALUES "
          "('schema_version', '${migration.version}', "
          '${DateTime.now().millisecondsSinceEpoch})',
        );
        await customStatement('COMMIT');
      } on Object catch (error) {
        await customStatement('ROLLBACK');
        throw MigrationFailed(
          migrationFile: migration.fileName,
          version: migration.version,
          cause: error.toString(),
        );
      }
      applied.add(migration.fileName);
    }

    return MigrationOutcome(
      fromVersion: from,
      toVersion: kLatestSchemaVersion,
      applied: applied,
      durationMs: DateTime.now().difference(started).inMilliseconds,
    );
  }

  /// The audited report from `008_integrity.sql` — the same 15 critical and 6
  /// warning checks `tool/verify_schema.sh` runs, read from Dart so the app can
  /// refuse to trust its own numbers and say so.
  Future<List<IntegrityFinding>> integrityReport() async {
    final rows = await customSelect(
      'SELECT severity, kind, detail, entity_id FROM v_integrity_report',
    ).get();
    return rows.map(IntegrityFinding.fromRow).toList(growable: false);
  }

  /// Critical findings only — what blocks posting a journal entry.
  Future<List<IntegrityFinding>> criticalFindings() async {
    final all = await integrityReport();
    return all.where((f) => f.isCritical).toList(growable: false);
  }

  Future<String> _recordedChecksum(String fileName) async {
    final rows = await customSelect(
      "SELECT value FROM schema_meta WHERE key = 'migration.$fileName.sha256'",
    ).get();
    return rows.isEmpty ? '' : rows.first.read<String>('value');
  }

  Future<String?> _sessionFlag(String key) async {
    final rows = await customSelect(
      'SELECT value FROM session_flags WHERE key = ?',
      variables: [Variable<String>(key)],
    ).get();
    return rows.isEmpty ? null : rows.first.read<String?>('value');
  }

  Future<void> _setSessionFlag(String key, String value) => customStatement(
        'INSERT OR REPLACE INTO session_flags (key, value) VALUES (?, ?)',
        [key, value],
      );

  Future<int> _quickCheck() async {
    final rows = await customSelect('PRAGMA quick_check(1)').get();
    final value = rows.isEmpty ? 'ok' : rows.first.data.values.first?.toString();
    return value == 'ok' ? 0 : 1;
  }
}

/// The singleton owner: one instance per process, one connection per instance.
final class KhataDb {
  KhataDb._(this.db, this._request);

  static KhataDb? _instance;
  static Future<KhataDb>? _opening;

  /// The drift handle every DAO uses.
  final KhataDatabase db;
  final KhataOpenRequest _request;

  BootDiagnostics get diagnostics => db.diagnostics;

  static KhataDb? get maybeInstance => _instance;
  static bool get isOpen => _instance != null;

  /// The open database. Throws if [open] has not completed — a loud failure
  /// beats a lazily-created second connection.
  static KhataDb get instance {
    final instance = _instance;
    if (instance == null) {
      throw StateError(
        'KhataDb.open() has not completed. DAOs must not be constructed before '
        'the database is open — see lib/data/db/database_init.dart.',
      );
    }
    return instance;
  }

  /// Opens the database, or returns the already-open one.
  ///
  /// Two callers racing (a warm-up in `main` and a provider) share one future.
  /// Two callers asking for *different* files is an error: two live databases
  /// means two writers and, in a ledger, two truths.
  static Future<KhataDb> open(KhataOpenRequest request) {
    final existing = _instance;
    if (existing != null) {
      if (existing._request.databaseFile.path != request.databaseFile.path) {
        throw StateError(
          'a KhataPro database is already open at '
          '${existing._request.databaseFile.path}; refusing to open a second '
          'one at ${request.databaseFile.path}. Close the first, or switch '
          'books inside the open database (ledgers table).',
        );
      }
      return Future<KhataDb>.value(existing);
    }
    return _opening ??= _openInternal(request);
  }

  static Future<KhataDb> _openInternal(KhataOpenRequest request) async {
    try {
      return await _openInternalImpl(request);
    } on Object {
      // A failed attempt must not be cached: without this, the first failure
      // (a wrong passphrase, a locked keystore, a refused read pool) would be
      // returned to every later caller as the same completed-with-error future,
      // and "try again" could never work.
      _opening = null;
      rethrow;
    }
  }

  static Future<KhataDb> _openInternalImpl(KhataOpenRequest request) async {
    final started = DateTime.now();
    final file = request.databaseFile;

    if (request.readPool != 0) {
      // Not an `assert`: this must fail in release builds too. A read pool means
      // extra isolates, each needing its own connection and its own key.
      throw const StorageException(
        message: 'readPool must be 0 (exactly one connection). Opening the '
            'database repeatedly is the thing this class exists to prevent.',
        recoverable: false,
      );
    }

    final parent = file.parent;
    if (!parent.existsSync()) {
      parent.createSync(recursive: true);
    }

    final handle = KhataDatabase(
      // One connection, in a background isolate, with the key attached in
      // `setup` — which runs on the connection before anything else touches it.
      NativeDatabase.createInBackground(
        file,
        readPool: 0,
        cachePreparedStatements: true,
        setup: (connection) {
          // The key must be the very first statement on this connection. If the
          // linked SQLite cannot encrypt, this throws inside the isolate and the
          // first query below fails with a message that says so.
          request.key.attachTo(connection, requireEncryption: request.requireEncryption);
        },
        isolateSetup: () {
          // Deliberately empty: SQLCipher arrives through the pubspec `hooks:`
          // block, so the old `open.overrideFor(...)` / 
          // `applyWorkaroundToOpenSqlite3OnOldAndroidVersions()` ritual is gone
          // (see docs/THIRD_PARTY.md).
        },
      ),
      assetLoader: request.assetLoader,
      nodeId: request.nodeId,
      requireEncryption: request.requireEncryption,
    );
    handle.hlcPersistence = request.hlcPersistence;

    final instance = KhataDb._(handle, request);
    try {
      // This is what runs `beforeOpen`: pragmas, migrations, HLC restore,
      // dirty-open recovery, integrity read.
      await handle.customSelect('SELECT 1').get();
    } on Object catch (error, stackTrace) {
      try {
        await handle.close();
      } on Object {
        // Nothing useful to do; the original error is the story.
      }
      _opening = null;
      Error.throwWithStackTrace(
        StorageException(
          message: 'the database could not be opened: $error',
          cause: error,
          recoverable: false,
        ),
        stackTrace,
      );
    }

    handle.diagnostics.openMillis =
        DateTime.now().difference(started).inMilliseconds;
    _instance = instance;
    _opening = null;
    return instance;
  }

  /// Closes the database — the counterpart to [open], and the only other place
  /// connection state changes.
  ///
  /// Flushes logical time, clears the dirty-open flag (a clean close is what
  /// makes the *next* open cheap), checkpoints the WAL, then disposes. Safe to
  /// call twice, and safe to call when the database never opened.
  Future<void> close() async {
    if (identical(_instance, this)) {
      _instance = null;
      _opening = null;
    }
    try {
      await db.hlc.flush();
      await db.customStatement(
        "INSERT OR REPLACE INTO session_flags (key, value) VALUES ('dirty_open', '0')",
      );
      await db.customStatement(
        "INSERT OR REPLACE INTO session_flags (key, value) VALUES "
        "('last_close_at', '${DateTime.now().millisecondsSinceEpoch}')",
      );
      await db.customStatement('PRAGMA wal_checkpoint(TRUNCATE)');
    } on Object {
      // A close-time failure must never mask why the app was closing.
    }
    await db.close();
  }

  @override
  String toString() => 'KhataDb(${_request.databaseFile.path})';
}

/// KhataPro · attaching the SQLCipher key to a raw connection.
///
/// This is the only place in the app that talks to SQLCipher's pragmas, and it
/// is deliberately small, ordered, and verified.
///
/// ## Why the key is passed as a raw key, not a passphrase
///
/// SQLCipher accepts two forms:
///
///   * `PRAGMA key = 'my passphrase'` — SQLCipher runs **PBKDF2-HMAC-SHA512,
///     256 000 iterations** on every single `sqlite3_open`. That is the
///     "expensive key derivation" that makes people believe SQLCipher is slow
///     and that repeatedly opening a connection is a performance disaster.
///   * `PRAGMA key = "x'<64 hex chars>'"` — a **raw 32-byte key**: the KDF is
///     skipped entirely. The expensive derivation has already been paid exactly
///     once, when the DEK was unwrapped from the keystore (see `key_custody.dart`).
///
/// KhataPro always uses the raw form. A consequence worth stating: even though
/// the connection is a strict singleton (see `database.dart`), the cost of a
/// *hypothetical* re-open is not a second KDF — it is a keystore unwrap plus
/// page-cache warm-up. Both are avoided by the singleton, and both are cheap
/// enough that a crash-recovery reopen does not punish the user.
///
/// ## Fail closed, never open
///
/// On a build without SQLCipher, `PRAGMA key` is an *unknown pragma*, which
/// SQLite ignores **silently**. The database would be created unencrypted and
/// nothing would look wrong until someone inspected the file. So [attachTo]
/// probes `cipher_version` and — unless the caller explicitly opts out — throws
/// [EncryptionUnavailable] rather than continuing in the clear. The opt-out
/// exists only for the verification harness, which runs against stock SQLite;
/// no production code path passes it.
library;

import 'dart:typed_data';

import 'package:sqlite3/sqlite3.dart';

import 'hasher.dart';

/// What the linked SQLite library actually did.
enum EncryptionMode {
  /// SQLCipher is linked and the key was applied.
  sqlcipher('sqlcipher'),

  /// Stock SQLite: no encryption. Only reachable when a caller passes
  /// `requireEncryption: false` (the harness) — never on a device build.
  none('none');

  const EncryptionMode(this.id);
  final String id;
}

/// Raised when the app was asked to encrypt but the linked library cannot.
class EncryptionUnavailable implements Exception {
  EncryptionUnavailable(this.message);
  final String message;

  @override

/// Raised when the key is wrong or the file is not a KhataPro database. SQLCipher
/// reports both as "file is not a database", which is intentional: it does not
/// tell an attacker which of the two it was.
class SqlCipherOpenFailure implements Exception {
  SqlCipherOpenFailure(this.message, {this.cause});
  final String message;
  final Object? cause;

  @override
  String toString() => 'SqlCipherOpenFailure: $message';

/// A key, in the form SQLCipher wants it.
final class SqlCipherKey {
  /// A raw 32-byte key (256-bit AES). This is the form this app always uses.
  SqlCipherKey.raw(Uint8List key)
      : _raw = Uint8List.fromList(key),
        _passphrase = null {
    if (key.length != 32) {
      throw ArgumentError.value(key.length, 'key.length',
          'SQLCipher raw keys are exactly 32 bytes (256-bit)');
    }
  }

  /// A passphrase. Supported for restoring a database that was created by an
  /// older build or by hand with a passphrase key; the app itself never creates
  /// one this way.
  SqlCipherKey.passphrase(String passphrase)
      : _raw = null,
        _passphrase = passphrase {
    if (passphrase.isEmpty) {
      throw ArgumentError.value(passphrase, 'passphrase', 'must not be empty');
    }
  }

  /// 32 fresh random bytes, for a brand-new database.
  static SqlCipherKey generate() => SqlCipherKey.raw(randomBytes(32));

  final Uint8List? _raw;
  final String? _passphrase;

  bool get isRawKey => _raw != null;

  /// The literal SQL value: `x'…'` or a quoted, escaped string.
  String get pragmaValue {
    final raw = _raw;
    if (raw != null) {
      return "x'${_hex(raw)}'";
    }
    // Single quotes are doubled per SQL string escaping. A passphrase
    // containing a quote must not be able to terminate the literal.
    final escaped = _passphrase!.replaceAll("'", "''");
    return "'$escaped'";
  }

  /// Never print the key. Any diagnostic that includes this object gets a red
  /// flag instead of a credential.
  @override
  String toString() =>
      isRawKey ? 'SqlCipherKey.raw(redacted)' : 'SqlCipherKey.passphrase(redacted)';

  /// Applies the key pragmas to a freshly opened connection and verifies the
  /// result.
  ///
  /// Order matters and is not arbitrary:
  ///   1. `key` first — before any other statement touches the file.
  ///   2. `cipher_page_size` before the first write on a new database, and it
  ///      must match the existing file otherwise.
  ///   3. `kdf_iter` / cipher algorithm pragmas only matter for passphrase
  ///      keys; they are skipped for raw keys (which bypass the KDF) and are
  ///      set explicitly for passphrase keys so a file written by a different
  ///      SQLCipher default still opens.
  ///   4. A probe statement — `SELECT count(*) FROM sqlite_master` — which is
  ///      what actually forces SQLCipher to verify the key. Without it, a wrong
  ///      key is not discovered until the first real query, far from the code
  ///      that could explain it.
  EncryptionMode attachTo(
    Database database, {
    bool requireEncryption = true,
    int pageSize = 4096,
    int kdfIterations = 256000,
    bool memorySecurity = true,
  }) {
    // ── Probe FIRST, before any cipher pragma is issued.
    //
    // On a stock SQLite build `PRAGMA key = x'…'` is not an unknown pragma that
    // gets ignored — the blob literal is a *syntax error*, so the statement
    // throws. Discovering that after attempting the key would mean guessing
    // whether the throw meant "no SQLCipher" or "wrong key". Asking
    // `cipher_version` first makes the two cases unambiguous, and it happens
    // before the file is touched at all.
    var mode = probe(database);

    if (mode == EncryptionMode.none) {
      if (requireEncryption) {
        throw EncryptionUnavailable(
          'the linked SQLite is not SQLCipher, so this database would be '
          'written UNENCRYPTED. Refusing to continue. Enable SQLCipher in '
          'pubspec.yaml under hooks: user_defines: sqlite3: source: sqlcipher, '
          'and rebuild. (requireEncryption: false exists only for the '
          'verification harness, which runs against stock SQLite.)',
        );
      }
      // Harness path: no cipher pragmas at all, so a stock build never sees a
      // statement it cannot parse.
      return EncryptionMode.none;
    }

    try {
      database.execute('PRAGMA key = $pragmaValue');
    } on SqliteException catch (error) {
      throw SqlCipherOpenFailure('PRAGMA key was rejected', cause: error);
    }

    database.execute('PRAGMA cipher_page_size = $pageSize');
    if (!isRawKey) {
      database.execute('PRAGMA kdf_iter = $kdfIterations');
      database.execute('PRAGMA cipher_hmac_algorithm = HMAC_SHA512');
      database.execute('PRAGMA cipher_kdf_algorithm = PBKDF2_HMAC_SHA512');
    }
    if (memorySecurity) {
      // Zeroes SQLCipher's internal key/plaintext buffers. A small CPU cost in
      // exchange for keys not lingering in freed heap memory — which matters
      // most on a device that will be sold on with its storage intact.
      database.execute('PRAGMA cipher_memory_security = ON');
    }

    // Force key validation here, while the error can still be explained: a wrong
    // key and a non-KhataPro file both report "file is not a database", and
    // nothing tells the user which.
    try {
      database.select('SELECT count(*) FROM sqlite_master');
    } on SqliteException catch (error) {
      throw SqlCipherOpenFailure(
        'the database could not be read with this key (wrong key, or the file '
        'is not a KhataPro database)',
        cause: error,
      );
    }

    mode = probe(database);
    return mode;
  }

  /// What the linked library supports. Empty result ⇒ stock SQLite.
  static EncryptionMode probe(Database database) {
    try {
      final rows = database.select('PRAGMA cipher_version');
      if (rows.isEmpty) return EncryptionMode.none;
      final value = rows.first.values.first;
      return (value is String && value.isNotEmpty)
          ? EncryptionMode.sqlcipher
          : EncryptionMode.none;
    } on SqliteException {
      // A build without the pragma at all throws in some configurations.
      return EncryptionMode.none;
    }
  }

  /// The SQLCipher version string, for the diagnostics bundle and Settings.
  static String? cipherVersion(Database database) {
    try {
      final rows = database.select('PRAGMA cipher_version');
      if (rows.isEmpty) return null;
      final value = rows.first.values.first;
      return value is String && value.isNotEmpty ? value : null;
    } on SqliteException {
      return null;
    }
  }
}

/// Passphrase-derived custody: Argon2id over the user's passphrase, in memory
/// only, verified by the envelope MAC rather than by a stored hash.
///
/// Note the deliberate absence of a password hash: there is no "verify the
/// passphrase" step, because a wrong passphrase simply fails to authenticate the
/// wrapped key. Nothing anywhere in the database tells an attacker whether a
/// guess was close.
final class PassphraseKeyCustody implements KeyCustody {
  PassphraseKeyCustody._({required DerivedKey kek, required String kekId})
      : _kek = kek,
        _kekId = kekId;

  /// Derives a KEK from [passphrase] and [salt] and returns custody for it.
  static Future<PassphraseKeyCustody> derive({
    required String passphrase,
    required Uint8List salt,
    KdfParams params = KdfParams.argon2idDefault,
    KeyDerivation derivation = const Pbkdf2KeyDerivation(),
    String? kekId,
  }) async {
    final key = await derivation.derive(passphrase, salt: salt, params: params);
    return PassphraseKeyCustody._(
      kek: key,
      kekId: kekId ?? 'passphrase:${params.algorithm}',
    );
  }

  DerivedKey? _kek;
  String _kekId;
  static const AeadKeyWrap _wrap = AeadKeyWrap();

  @override
  CustodyLevel get level => CustodyLevel.passphraseWrapped;

  @override
  String get kekId => _kekId;

  /// True while the passphrase-derived key is in memory.
  bool get isUnlocked => _kek != null;

  @override
  Future<WrapEnvelope> wrap(Uint8List dek, {required String keyId}) async {
    final kek = _requireKek().bytes;
    return _wrap.seal(
      kek: kek,
      plaintext: dek,
      keyId: keyId,
      salt: _requireKek().salt,
    );
  }

  @override
  Future<Uint8List> unwrap(WrapEnvelope envelope) async =>
      _wrap.open(kek: _requireKek().bytes, envelope: envelope);

  /// Drops the derived key from memory. Called on app lock and on pause-after-
  /// timeout. Zeros the buffer first: Dart gives no guarantee that the old
  /// allocation is not still in a heap page, but not zeroing it guarantees it
  /// *is*.
  @override
  Future<void> destroy() async {
    final kek = _kek;
    if (kek != null) {

///

/// KhataPro · Hybrid Logical Clock.
///
/// An HLC is `(physical milliseconds, logical counter, node id)` — a wall clock
/// glued to a Lamport counter so that
///
///   1. time never goes backwards, even when the device clock does, and
///   2. two events on two devices are *totally* ordered without any
///      coordination, which is precisely what a server-free CRDT needs.
///
/// The encoding is intentionally fixed-width (57 characters):
///
///     `00000001800000000:0001:11111111-1111-7111-8111-000000000001`
///      └── 15 digits ──┘ └4 hex┘ └────────── 36 UUID ──────────┘
///
/// Because every field is zero-padded, SQLite's ordinary BINARY collation
/// orders the encoded strings *exactly* as causal time orders them. That single
/// property is why the sync layer needs no custom collation, no per-row parsing
/// during a delta scan, and no index on anything but a plain TEXT column.
///
/// The class is pure Dart (no `package:` imports) so it can be exercised by
/// `tool/crdt_verify.dart` and property-tested without a Flutter toolchain.
library;


/// Why a warning was raised. Warnings are advisory, never fatal.
enum HlcWarningKind {
  /// A peer's physical clock is far ahead of ours; its stamp was clamped for
  /// the purpose of advancing *our* clock (the row keeps the peer's own stamp).
  remoteClockAhead,

  /// A peer's physical clock is far behind; harmless, noted for diagnostics.
  remoteClockBehind,

  /// 65 536 events inside one millisecond — the counter rolled into a new ms.
  counterOverflow,

  /// The device clock jumped backwards; logical time absorbed the shock.
  localClockWentBackwards,
}

final class HlcWarning {
  const HlcWarning(this.kind, this.detail, this.atMs);
  final HlcWarningKind kind;
  final String detail;
  final int atMs;

/// An immutable hybrid logical clock reading.
final class Hlc implements Comparable<Hlc> {
  /// Fast constructor for trusted internal call sites (skips UUID validation).
  const Hlc.unchecked(this.physicalMs, this.counter, this.nodeId);

  factory Hlc.of({
    required int physicalMs,
    required int counter,
    required String nodeId,
  }) {
    if (physicalMs < 0 || physicalMs > maxPhysicalMs) {
      throw ArgumentError.value(physicalMs, 'physicalMs', 'out of range 0..$maxPhysicalMs');
    }
    if (counter < 0 || counter > maxCounter) {
      throw ArgumentError.value(counter, 'counter', 'out of range 0..$maxCounter');
    }
    if (!isValidNodeId(nodeId)) {
      throw ArgumentError.value(nodeId, 'nodeId', 'must be a lowercase 36-char UUID');
    }
    return Hlc.unchecked(physicalMs, counter, nodeId);
  }

  /// Milliseconds since the Unix epoch, as the *writer* observed it.
  final int physicalMs;

  /// Logical counter disambiguating events inside the same millisecond.
  final int counter;

  /// The writing device's UUIDv7. Also the final tie-breaker of the order.
  final String nodeId;

  static const int maxCounter = 0xFFFF;
  static const int maxPhysicalMs = 999999999999999; // 15 digits
  static const int encodedLength = 57;
  static const int physicalDigits = 15;
  static const int counterDigits = 4;
  static const int nodeIdLength = 36;

  /// The smallest possible HLC: used for seeded rows, seeds and "beginning of
  /// time" cursors. Zero HLCs lose to every real write, which is what makes
  /// seed data merge-cost-free across independently installed devices.
  factory Hlc.zero(String nodeId) => Hlc.unchecked(0, 0, nodeId);

  factory Hlc.seed() => const Hlc.unchecked(0, 0, seedNodeId);

  /// Synthetic node id used by 007_seed.sql for deterministic seed rows.
  static const String seedNodeId = '00000000-0000-7000-8000-000000000000';

  // ── encoding ────────────────────────────────────────────────────────────

  /// The 57-character form stored in `hlc` columns and compared bytewise.
  String encode() => [
        physicalMs.toString().padLeft(physicalDigits, '0'),
        counter.toRadixString(16).padLeft(counterDigits, '0'),
        nodeId,
      ].join(':');

  /// Strict parse. Rejects anything that would break bytewise ordering — a
  /// lenient parser here would silently corrupt causal ordering, which is the
  /// one thing the sync layer cannot recover from.
  static Hlc parse(String encoded) {
    final result = tryParse(encoded);
    if (result == null) {
      throw FormatException('malformed HLC (expected $encodedLength chars '
          'PPPPPPPPPPPPPPP:CCCC:<uuid>)', encoded);
    }
    return result;
  }

  static Hlc? tryParse(String encoded) {
    if (encoded.length != encodedLength) return null;
    if (encoded[physicalDigits] != ':' || encoded[physicalDigits + 1 + counterDigits] != ':') {
      return null;
    }
    final physicalPart = encoded.substring(0, physicalDigits);
    final counterPart = encoded.substring(
        physicalDigits + 1, physicalDigits + 1 + counterDigits);
    final nodePart = encoded.substring(physicalDigits + 1 + counterDigits + 1);

    for (final unit in physicalPart.codeUnits) {
      if (unit < 0x30 || unit > 0x39) return null; // must be zero-padded decimal
    }
    for (final unit in counterPart.codeUnits) {
      final isDigit = unit >= 0x30 && unit <= 0x39;
      final isLowerHex = unit >= 0x61 && unit <= 0x66;
      if (!isDigit && !isLowerHex) return null;
    }
    if (!isValidNodeId(nodePart)) return null;

    final physical = int.tryParse(physicalPart);
    final counter = int.tryParse(counterPart, radix: 16);
    if (physical == null || counter == null) return null;
    return Hlc.unchecked(physical, counter, nodePart);
  }

  static bool isValidNodeId(String nodeId) {
    if (nodeId.length != nodeIdLength) return false;
    for (var i = 0; i < nodeId.length; i++) {
      final unit = nodeId.codeUnitAt(i);
      final isDash = unit == 0x2D;
      final isHex = (unit >= 0x30 && unit <= 0x39) || (unit >= 0x61 && unit <= 0x66);
      if (!isDash && !isHex) return false;
    }
    // Standard UUID dash positions (8-4-4-4-12).
    return nodeId[8] == '-' && nodeId[13] == '-' && nodeId[18] == '-' && nodeId[23] == '-';

    if (counter != other.counter) return counter.compareTo(other.counter);

  bool operator <=(Hlc other) => compareTo(other) <= 0;
  bool operator >(Hlc other) => compareTo(other) > 0;
  bool operator >=(Hlc other) => compareTo(other) >= 0;

  bool sameNode(Hlc other) => nodeId == other.nodeId;

  /// True when this reading comes from [other]'s writer at a strictly earlier

  bool isBefore(Hlc other) => compareTo(other) < 0;

/// Mutable clock that produces monotonic [Hlc] readings for one device.
///
/// One instance per process (see `HlcService`), fed by [tick] for local writes
/// and [observe] for every incoming remote stamp — including your own stamps
/// read back from the database on startup, which is what stops a clock that
/// went backwards from handing out stamps the database's monotonicity guard
/// would then reject.
final class HlcClock {
  HlcClock({required this.nodeId, int? startPhysicalMs})
      : _physical = startPhysicalMs ?? 0,
        _counter = 0 {
    if (!Hlc.isValidNodeId(nodeId)) {
      throw ArgumentError.value(nodeId, 'nodeId', 'must be a lowercase 36-char UUID');
    }
  }

  /// How far ahead of local time a peer's stamp may drag our clock. Beyond
  /// this we clamp for *local advancement* purposes (the peer's own row keeps
  /// its original stamp, untouched) so one phone with a broken clock cannot
  /// push every subsequent local write into the year 3000.
  static const int maxDriftMs = 5 * 60 * 1000;

  /// How many anomalies to retain for diagnostics before dropping the oldest.
  static const int maxWarnings = 50;

  final String nodeId;
  int _physical;
  int _counter;
  final List<HlcWarning> _warnings = [];
  final List<HlcWarning> _allWarnings = [];

  /// Readings emitted so far (diagnostics + tests).
  int _emitted = 0;
  int get emittedCount => _emitted;

  /// The most recent reading; also the value to persist as `last_hlc` so the
  /// next process start resumes logical time instead of restarting it.
  Hlc get last => Hlc.unchecked(_physical, _counter, nodeId);

  /// Recent warnings (bounded ring — never grows without limit in a long-lived
  /// process, which matters on a device that stays open for days).
  List<HlcWarning> get warnings => List.unmodifiable(_warnings);

  /// Every warning since construction, for the diagnostics screen.
  List<HlcWarning> get allWarnings => List.unmodifiable(_allWarnings);

  int get physicalMs => _physical;
  int get counter => _counter;

  /// Resume from the last persisted reading after an app restart, so logical
  /// time never regresses across sessions.
  void restore(Hlc lastSeen) {
    if (lastSeen.physicalMs > _physical ||
        (lastSeen.physicalMs == _physical && lastSeen.counter > _counter)) {
      _physical = lastSeen.physicalMs;
      _counter = lastSeen.counter;
    }
  }

  /// Local event (a write by this device).
  ///
  /// `tick(nowMs)`:
  ///   · clock advanced            → adopt wall time, reset the counter
  ///   · clock same or went back   → keep logical time, bump the counter
  Hlc tick(int nowMs) {
    if (nowMs > _physical) {
      _physical = nowMs;
      _counter = 0;
    } else {
      if (nowMs < _physical) {
        _warn(HlcWarningKind.localClockWentBackwards,
            'device clock reports ${nowMs - _physical} ms earlier than logical time; '
            'keeping logical time ahead', nowMs);
      }
      _counter++;
      if (_counter > Hlc.maxCounter) {
        _physical++;
        _counter = 0;
        _warn(HlcWarningKind.counterOverflow,
            'more than ${Hlc.maxCounter + 1} events in one millisecond', nowMs);
      }
    }
    return _emit();
  }

  /// Remote event (an oplog row or replicated snapshot from a peer).
  ///
  /// Returns the **local clock after absorbing the remote reading** — which is
  /// always strictly greater than the remote stamp, so the next local write is
  /// correctly ordered after everything we have seen. This is the standard HLC
  /// receive rule; the deviation worth noting is the clamping at
  /// [maxDriftMs], which trades a sliver of theoretical causal fidelity for
  /// immunity to a peer with a badly wrong clock.
  Hlc observe(Hlc remote, int nowMs) {
    var remotePhysical = remote.physicalMs;
    if (remotePhysical > nowMs + maxDriftMs) {
      _warn(HlcWarningKind.remoteClockAhead,
          'peer ${remote.nodeId} is ${(remotePhysical - nowMs) ~/ 1000}s ahead; '
          'clamping to +${maxDriftMs ~/ 1000}s for local advancement '
          '(their stored stamp is unchanged)', nowMs);
      remotePhysical = nowMs + maxDriftMs;
    } else if (nowMs - remotePhysical > maxDriftMs) {
      _warn(HlcWarningKind.remoteClockBehind,
          'peer ${remote.nodeId} is ${(nowMs - remotePhysical) ~/ 1000}s behind', nowMs);
    }

    final maxPhysical = _max3(_physical, nowMs, remotePhysical);
    if (maxPhysical == _physical && maxPhysical == remotePhysical) {
      _counter = (counter > remote.counter ? counter : remote.counter) + 1;
    } else if (maxPhysical == _physical) {
      _counter++;
    } else if (maxPhysical == remotePhysical) {
      _counter = remote.counter + 1;
    } else {
      _counter = 0;
    }
    if (_counter > Hlc.maxCounter) {
      _physical = maxPhysical + 1;
      _counter = 0;
      _warn(HlcWarningKind.counterOverflow, 'counter overflow while merging a remote stamp', nowMs);
      return _emit();
    }
    _physical = maxPhysical;
    return _emit();
  }

  /// Absorb many remote stamps (a whole applied batch) in one pass.
  Hlc observeAll(Iterable<Hlc> remotes, int nowMs) {
    for (final remote in remotes) {
      if (remote.compareTo(last) > 0) observe(remote, nowMs);
    }
    return last;
  }

  Hlc _emit() {
    _emitted++;
    return Hlc.unchecked(_physical, _counter, nodeId);
  }

/// KhataPro · the process-wide clock and stamp factory.
///
/// One instance per process, owned by `DatabaseOpen` and shared by every DAO
/// through Riverpod. It exists as a service (rather than a bare [HlcClock])
/// because the clock has to survive two awkward moments:
///
///   · **App start.** Logical time must not restart at 0, or a device whose
///     real clock is behind would hand out stamps that *lose* to rows it wrote
///     yesterday — and the database's monotonicity guard (INT-7e) would reject
///     the write. So the last emitted stamp is persisted in `session_flags` and
///     restored on open.
///   · **App lock.** When the user locks the app we close the database (the
///     key leaves memory). The clock keeps running so that background
///     notifications still stamp correctly, and it is re-persisted on unlock.
///
/// Pure Dart on purpose: it is exercised by `tool/crdt_verify.dart` and by the
/// data-layer harness without a Flutter toolchain.
library;

import 'hlc.dart';
import 'stamp.dart';

/// A clock value that can be persisted across runs.
abstract interface class HlcPersistence {
  /// Reads the last emitted stamp (null on a fresh install).
  Future<String?> readLastHlc();

  /// Persists the last emitted stamp. Must be cheap: called at most every
  /// [HlcService.persistInterval] writes, never on the write path's critical
  /// section.
  Future<void> writeLastHlc(String hlc);
}

/// In-memory persistence for tests and for the (rare) unlocked-first-run case.
final class MemoryHlcPersistence implements HlcPersistence {
  String? _value;

  @override
  Future<String?> readLastHlc() async => _value;

  @override
  Future<void> writeLastHlc(String hlc) async => _value = hlc;
}

/// Process-wide clock + stamp factory.
final class HlcService {
  HlcService({required this.nodeId, HlcPersistence? persistence})
      : persistence = persistence ?? MemoryHlcPersistence(),
        _clock = HlcClock(nodeId: nodeId);

  /// This device's UUIDv7 (the `nodes.node_id` row).
  final String nodeId;
  final HlcPersistence persistence;
  final HlcClock _clock;

  /// How many writes may pass between persistence flushes. Persisting on every
  /// write would add an fsync to every keystroke-level save; not persisting at
  /// all would let a crash rewind logical time by however much we had advanced.
  /// 64 writes (~a burst of activity) is the balance, and [flush] is also
  /// called on app pause, lock and shutdown.
  static const int persistInterval = 64;

  int _writesSinceFlush = 0;
  Hlc? _lastFlushed;

  /// Wall clock, injectable so tests can drive time deterministically.
  int Function() nowMs = () => DateTime.now().millisecondsSinceEpoch;

  /// The most recent reading emitted.
  Hlc get last => _clock.last;

  /// Diagnostics surfaced in Settings → Sync health.
  List<HlcWarning> get warnings => _clock.warnings;

  /// Loads the persisted stamp and seeds logical time from it. Called once,
  /// during database open, before any write.
  Future<void> load() async {
    final stored = await persistence.readLastHlc();
    if (stored == null) return;
    final parsed = Hlc.tryParse(stored);
    if (parsed == null) return; // corrupt persisted value: start fresh, never throw
    _clock.restore(parsed);
  }

  /// Local write: the stamp for a row this device is touching now.
  CrdtStamp stampForWrite() {
    final stamp = CrdtStamp(hlc: _clock.tick(nowMs()), rev: 1);
    _afterEmit();
    return stamp;
  }

  /// Local update to an existing row: `rev` advances.
  CrdtStamp stampForUpdate(CrdtStamp current) {
    final stamp = current.bump(_clock, nowMs());
    _afterEmit();
    return stamp;
  }

  /// Observe a remote stamp (from an applied batch). Called for every row a
  /// peer sends, so the next local write is ordered after everything seen.
  void observe(Hlc remote) {
    if (remote > _clock.last) _clock.observe(remote, nowMs());
  }

  /// Observe a whole batch in one pass (the sync applier calls this once per
  /// transaction instead of once per row).
  void observeAll(Iterable<Hlc> remotes) {
    final cutoff = _clock.last;
    for (final remote in remotes) {
      if (remote > cutoff) _clock.observe(remote, nowMs());
    }
  }

  /// Force a persist (app pause, lock, shutdown, before a backup).
  Future<void> flush() async {
    final last = _clock.last;
    if (_lastFlushed == last) return;
    await persistence.writeLastHlc(last.encode());
    _lastFlushed = last;
    _writesSinceFlush = 0;
  }

  void _afterEmit() {
    if (++_writesSinceFlush >= persistInterval) {
      // Deliberately not awaited: the write path must not block on I/O. A lost
      // flush costs at most `persistInterval` stamps of clock advancement,
      // which the HLC absorbs on the next open without any correctness impact.
      unawaited(flush());
    }
  }

  @override
  String toString() => 'HlcService($nodeId, last=${_clock.last.encode()})';
}

  future.ignore();

/// Canonical JSON: sorted keys, no whitespace, integers only.
///
/// "Canonical" here means *byte-identical on every platform and every Dart
/// version*, which is what lets two devices compare payloads for equality.
/// `jsonEncode` alone is not enough — a `Map` iterates in insertion order, and
/// two devices will have built their maps in different orders.
///
/// Doubles are **rejected**, not rounded: a double in a payload means a float
/// leaked into money or quantities somewhere upstream, and this is the last
/// line of defence that catches it before it reaches the sync wire.
String canonicalJson(Object? value) {
  final buffer = StringBuffer();
  _writeCanonical(buffer, value);
  return buffer.toString();
}

void _writeCanonical(StringBuffer buffer, Object? value) {
  switch (value) {
    case null:
      buffer.write('null');
    case bool():
      buffer.write(value ? 'true' : 'false');
    case int():
      buffer.write(value.toString());
    case String():
      buffer.write(_encodeString(value));
    case List<Object?>():
      buffer.write('[');
      for (var i = 0; i < value.length; i++) {
        if (i > 0) buffer.write(',');
        _writeCanonical(buffer, value[i]);
      }
      buffer.write(']');
    case Map<Object?, Object?>():
      final keys = value.keys.map((k) => k.toString()).toList()..sort();
      buffer.write('{');
      for (var i = 0; i < keys.length; i++) {
        if (i > 0) buffer.write(',');
        final key = keys[i];
        buffer
          ..write(_encodeString(key))
          ..write(':');
        _writeCanonical(buffer, value[key]);
      }
      buffer.write('}');
    default:
      throw ArgumentError(
        'canonicalJson: unsupported type ${value.runtimeType}. Payloads must be '
        'composed of null, bool, int, String, List and Map — money and '
        'quantities are integers of minor units, never doubles.',
      );
  }
}

/// JSON string escaping (RFC 8259) for the subset of characters Dart strings
/// can contain. Hand-rolled rather than delegated to `jsonEncode` so this file
/// keeps zero package dependencies and its behaviour is pinned by tests.
String _encodeString(String value) {
  final buffer = StringBuffer('"');
  for (final unit in value.codeUnits) {
    switch (unit) {
      case 0x22:
        buffer.write(r'\"');
      case 0x5C:
        buffer.write(r'\\');
      case 0x08:
        buffer.write(r'\b');
      case 0x0C:
        buffer.write(r'\f');
      case 0x0A:
        buffer.write(r'\n');
      case 0x0D:
        buffer.write(r'\r');
      case 0x09:
        buffer.write(r'\t');
      default:
        if (unit < 0x20) {
          buffer.write('\\u${unit.toRadixString(16).padLeft(4, '0')}');
        } else {
          buffer.writeCharCode(unit);
        }
    }
  }
  buffer.write('"');
  return buffer.toString();

/// KhataPro · the last-write-wins resolver.
///
/// This is the function that decides what happens when two devices that have
/// been offline for a week both edited the same customer. It runs identically
/// on every device, with no server, no negotiation and no user prompt, and it
/// must satisfy four properties:
///
///   1. **Deterministic** — every device that sees the same two versions picks
///      the same winner. Guaranteed by ordering on `(physical, counter, nodeId)`
///      only; `nodeId` is in the key precisely so that two writes in the same
///      millisecond cannot be ordered by "whichever arrived first locally".
///   2. **Idempotent** — replaying the same remote row changes nothing.
///      (Deliverable 5 depends on this: peers re-send freely.)
///   3. **Commutative** — applying A then B converges to the same state as B
///      then A. The merge of a *set* of rows is therefore order-free, which is
///      what makes the whole no-server sync design safe.
///   4. **Lossless in the sense that matters** — the losing value is never
///      silently dropped. Every field that differed is emitted as a
///      [FieldConflict] for `conflict_log`, so the user can review and reverse
///      a merge they disagree with. (A CRDT cannot preserve both values in one
///      column; pretending otherwise would be dishonest. Preserving the loser
///      *beside* the winner, with a review path, is the honest version of
///      "no data loss".)
///
/// Two situations the rules cannot resolve are reported as [MergeAnomaly]s, at
/// two different strengths — and the difference is deliberate:
///
///   * **Identical stamps, different content** (one writer, one logical instant,
///     two payloads) is *undecidable*: there is no ordering that is correct, only
///     a coin flip. The local copy is kept and the anomaly is **blocking**, so
///     the sync layer stops and asks rather than inventing an answer.
///   * **A revision that went backwards for one writer** (the signature of a
///     restored or rolled-back replica) is *decidable* — the newer HLC still wins
///     and no value is lost — so the merge proceeds and the anomaly is
///     **non-blocking**, a warning the sync layer turns into "ask this peer for a
///     fresh snapshot". Blocking here would strand a shopkeeper who merely
///     restored their phone from a backup, which is a normal Tuesday.
///
/// **Precondition:** every [StampedRow] carries the row's *complete* column set
/// (which the transport guarantees — the oplog re-reads the live row, and
/// tombstones carry `payload_json`). Merge receipts are computed field-by-field
/// against that complete set, so a partial payload would make them
/// order-dependent. This is asserted by the property test in
/// `tool/crdt_verify.dart`.
///
/// Pure Dart, no `package:` imports — property-tested by `tool/crdt_verify.dart`.
library;

import 'stamp.dart';

/// What the merge did.
enum MergeAction {
  /// The incoming row was newer and has replaced the local row.
  applied,

  /// The incoming row was older (or a tombstone that lost); local kept.
  keptLocal,

  /// Same stamp, same content — a replay. Nothing written, nothing logged.
  identical,

  /// The incoming row is newer and un-deletes a tombstoned row. Users do
  /// restore deleted parties; the review card says who did it and when.
  resurrected,
}

/// A single field that differed between the two versions.

/// Stateless resolver. Safe to share; every method is pure.
final class LwwResolver {
  const LwwResolver();

  /// Merge one incoming row into the local copy.
  ///
  /// Throws [ArgumentError] if the rows are for different ids — that would
  /// mean a bug in the caller (a mis-keyed map), and merging across ids is the
  /// sort of silent corruption this class exists to prevent.
  MergeOutcome merge({
    required StampedRow local,
    required StampedRow incoming,
  }) {
    if (local.rowId != incoming.rowId) {
      throw ArgumentError(
        'LWW cannot merge different rows: local=${local.rowId} incoming=${incoming.rowId}',
      );
    }

    final comparison = incoming.stamp.compareTo(local.stamp);

    // ── Case 1 · same stamp ────────────────────────────────────────────────
    if (comparison == 0) {
      if (local.sameContent(incoming)) {
        return MergeOutcome(action: MergeAction.identical, winner: local);
      }
      // One writer, one logical instant, two different payloads. Impossible
      // for a correct writer; either a bug or a forged op. We keep the local
      // copy (deterministic, no flapping) and raise a blocking anomaly rather
      // than silently choosing.
      return MergeOutcome(
        action: MergeAction.keptLocal,
        winner: local,
        loser: incoming,
        conflicts: _diffFields(loser: incoming, winner: local, resolution: 'kept_local_ambiguous'),
        anomalies: [
          MergeAnomaly(
            kind: 'same_stamp_different_content',
            detail: 'stamp ${incoming.stamp} carries two different payloads '
                '(local ${local.canonicalPayload().hashCode.toRadixString(16)}, '
                'remote ${incoming.canonicalPayload().hashCode.toRadixString(16)}); '
                'a writer must never reuse a stamp',
            rowId: local.rowId,
            tableName: local.tableName ?? incoming.tableName,
            blocking: true,
            remoteNode: incoming.stamp.nodeId,
          ),
        ],
      );
    }

    // ── Case 2 · strict ordering by HLC ────────────────────────────────────
    final incomingWins = comparison > 0;
    final winner = incomingWins ? incoming : local;
    final loser = incomingWins ? local : incoming;

    final anomalies = <MergeAnomaly>[];

    // Consistency guard: for a single writer, rev and hlc must advance
    // together. If they disagree, one of the two versions comes from a
    // restored/rolled-back replica — the sync layer should ask that peer to
    // re-send from a snapshot rather than trusting its stream.
    if (winner.stamp.sameWriter(loser.stamp) && winner.stamp.rev <= loser.stamp.rev) {
      anomalies.add(MergeAnomaly(
        kind: 'revision_not_monotonic',
        detail: 'writer ${winner.stamp.nodeId} produced hlc ${winner.stamp.hlc.encode()} '
            'with rev ${winner.stamp.rev} after rev ${loser.stamp.rev}; '
            'the writer\'s state may have been rolled back',
        rowId: local.rowId,
        tableName: local.tableName ?? incoming.tableName,
        remoteNode: incoming.stamp.nodeId,
      ));
    }

    final conflicts = winner.sameContent(loser)
        ? const <FieldConflict>[]
        : _diffFields(
            loser: loser,
            winner: winner,
            resolution: incomingWins ? 'remote_won' : 'local_won',
          );

    final action = switch ((incomingWins, local.isDeleted, incoming.isDeleted)) {
      (false, _, _) => MergeAction.keptLocal,
      (true, _, true) => MergeAction.applied,        // tombstone applied
      (true, true, false) => MergeAction.resurrected, // update beats old tombstone
      (true, false, false) => MergeAction.applied,
    };

    return MergeOutcome(
      action: action,
      winner: winner,
      loser: loser,
      conflicts: conflicts,
      anomalies: anomalies,
    );
  }

  /// Merge a batch, in any order, and return the converged state.
  ///
  /// Order-independence is a property of [merge], so this simply folds. The
  /// proof is not verbal: `tool/crdt_verify.dart` generates random op sets,
  /// applies them under hundreds of permutations, and asserts identical final
  /// state plus a complete conflict ledger.
  MergeBatchResult mergeAll({
    required Map<String, StampedRow> local,
    required Iterable<StampedRow> incoming,
  }) {
    final state = Map<String, StampedRow>.of(local);
    final conflicts = <FieldConflict>[];
    final anomalies = <MergeAnomaly>[];
    var applied = 0;
    var keptLocal = 0;
    var identical = 0;
    var resurrected = 0;

    for (final row in incoming) {
      final current = state[row.rowId];
      if (current == null) {
        // Brand-new replicated row: nothing to resolve.
        state[row.rowId] = row;
        applied++;
        continue;
      }
      final outcome = merge(local: current, incoming: row);
      state[row.rowId] = outcome.winner;
      conflicts.addAll(outcome.conflicts);
      anomalies.addAll(outcome.anomalies);
      switch (outcome.action) {
        case MergeAction.applied:
          applied++;
        case MergeAction.keptLocal:
          keptLocal++;
        case MergeAction.identical:
          identical++;
        case MergeAction.resurrected:
          resurrected++;
      }
    }

    return MergeBatchResult(
      state: state,
      conflicts: conflicts,
      anomalies: anomalies,
      applied: applied,
      keptLocal: keptLocal,
      identical: identical,
      resurrected: resurrected,
    );
  }

  /// Field-by-field receipts for the losing version.
  ///
  /// Note that this catches the genuinely useful case: device A changed the
  /// customer's phone number, device B changed the address. Row-level LWW picks
  /// one row, so one of those edits *is* lost — but both are reported here, the
  /// user sees a review card, and can restore the lost value with one tap.
  /// (Field-level stamps, which would preserve both automatically, are a
  /// schema change: a per-field vector in the oplog payload. Deliberately out
  /// of scope for v1 — the review path gives the same outcome with far less
  /// machinery, and it is honest about what happened.)
  List<FieldConflict> _diffFields({
    required StampedRow loser,
    required StampedRow winner,
    required String resolution,
  }) {
    final result = <FieldConflict>[];
    final winnerPayload = winner.payload;
    final loserPayload = loser.payload;
    final fields = <String>{...winnerPayload.keys, ...loserPayload.keys}..remove('deleted_at');
    final sorted = fields.toList()..sort();

    for (final field in sorted) {
      final winnerValue = winnerPayload[field];
      final loserValue = loserPayload[field];
      if (canonicalJson(winnerValue) == canonicalJson(loserValue)) continue;
      result.add(FieldConflict(
        rowId: winner.rowId,
        tableName: winner.tableName ?? loser.tableName,
        field: field,
        winnerValue: winnerValue,
        loserValue: loserValue,
        winnerNode: winner.stamp.nodeId,
        loserNode: loser.stamp.nodeId,
        winnerHlc: winner.stamp.hlc.encode(),
        loserHlc: loser.stamp.hlc.encode(),
        resolution: resolution,
      ));
    }

    // A tombstone flip is itself a content change worth reporting.
    if (winner.isDeleted != loser.isDeleted) {
      result.add(FieldConflict(
        rowId: winner.rowId,
        tableName: winner.tableName ?? loser.tableName,
        field: 'deleted_at',
        winnerValue: winner.deletedAt,
        loserValue: loser.deletedAt,
        winnerNode: winner.stamp.nodeId,
        loserNode: loser.stamp.nodeId,
        winnerHlc: winner.stamp.hlc.encode(),
        loserHlc: loser.stamp.hlc.encode(),
        resolution: resolution,
      ));
    }
    return result;
  }

  // ───────────────────────────────────────────────────────────────────────
  //  Pre-flight checks used by the writer side (before a local edit is saved)
  // ───────────────────────────────────────────────────────────────────────

  /// Verify the invariant that makes the whole scheme work: a new write's
  /// stamp must be strictly greater than the row's current stamp. If a caller
  /// ever hands us a stale stamp (a cached entity, a background job holding an
  /// old snapshot), this catches it in the app layer rather than letting the
  /// database trigger reject it with a less helpful message.
  static bool isStaleWrite({required StampedRow current, required CrdtStamp proposed}) =>
      proposed.compareTo(current.stamp) <= 0;

  /// Stamp guard for a batch of local edits: returns the ids whose proposed
  /// stamps would not advance the row.
  static List<String> findStaleWrites({
    required Map<String, StampedRow> current,
    required Map<String, CrdtStamp> proposed,
  }) {
    final stale = <String>[];
    for (final entry in proposed.entries) {
      final existing = current[entry.key];
      if (existing != null && isStaleWrite(current: existing, proposed: entry.value)) {
        stale.add(entry.key);
      }
    }
    stale.sort();
    return stale;
  }
}

/// Extension kept out of the public surface (see [MergeBatchResult]).
extension MergeBatchResultDiagnostics on MergeBatchResult {
  /// Human-readable one-liner for the sync health card.
  String get summary => isClean
      ? '$total ops merged cleanly (${conflicts.length} field receipts)'
      : '$total ops merged with ${anomalies.length} anomalies requiring review';
}

/// KhataPro · the shared plumbing every DAO uses.
///
/// Four things happen on **every** write in this app, and if any DAO forgets one
/// of them the merge story breaks in a way that only shows up on the second
/// device. So they live here, once:
///
///   1. **A causal stamp.** Every replicated row gets `(hlc, node_id, rev,
///      created_at, updated_at)`. `rev` advances on update; the HLC advances
///      always. The stamp is what the CRDT compares — never the wall clock,
///      which any device can change in Settings.
///   2. **An op-log entry**, so the change is offered to peers. Duplicate
///      delivery is expected and safe; a *missing* op-log row is data that never
///      reaches the other phone.
///   3. **A chained audit record** (`hash_prev` ‖ event). The chain is what makes
///      "an entry was edited after posting" detectable months later, from a
///      different device, without trusting the app that wrote it.

///      current version and it is not, we refuse *before* SQL rather than

/// Base class for every DAO. Holds the handle, this device's identity and the
/// ledger being worked in.
class DaoBase {
  DaoBase({required this.db, required this.ledgerId});

  final KhataDatabase db;

  /// The book being worked in. Every query is scoped by it — the schema's every
  /// view and the composite foreign keys depend on that discipline, and a
  /// missing `WHERE ledger_id = ?` is the one bug that could mix a shop's books
  /// with its workshop's.
  final String ledgerId;

  HlcService get hlc => db.hlc;
  String get nodeId => db.nodeId;

  /// Drift variables from a positional argument list.
  List<Variable<Object>> vars(List<Object?> args) =>
      [for (final arg in args) Variable<Object>(arg)];

  /// One row, or null.
  Future<QueryRow?> one(String sql, [List<Object?> args = const []]) async {
    final rows = await db.customSelect(sql, variables: vars(args)).get();
    return rows.isEmpty ? null : rows.first;
  }

  /// All rows.
  Future<List<QueryRow>> all(String sql, [List<Object?> args = const []]) =>
      db.customSelect(sql, variables: vars(args)).get();

  /// A single integer.
  Future<int> scalarInt(String sql, [List<Object?> args = const []]) async {
    final row = await one(sql, args);
    final value = row?.data.values.firstOrNull;
    return (value as num?)?.toInt() ?? 0;
  }

  /// A single string.
  Future<String?> scalarString(String sql, [List<Object?> args = const []]) async {
    final row = await one(sql, args);
    return row?.data.values.firstOrNull?.toString();
  }

  Future<void> exec(String sql, [List<Object?> args = const []]) =>
      db.customStatement(sql, args);

  /// Runs [work] in one SQL transaction on the single connection.
  ///
  /// Nested calls join the outer transaction (drift handles the savepoint
  /// semantics), so a service method can be composed into a bigger unit without
  /// ever opening a second write path.
  Future<T> inTransaction<T>(Future<T> Function() work) =>
      db.transaction(() => work());

  // ───────────────────────────────────────────────────────────────────────────
  //  Writes: the four things that must always happen
  // ───────────────────────────────────────────────────────────────────────────

  /// A fresh stamp for a row this device is creating.
  CrdtStamp newStamp() => hlc.stampForWrite();

  /// A stamp for updating an existing row: `rev` advances, HLC moves forward.
  CrdtStamp updateStamp(CrdtStamp current) => hlc.stampForUpdate(current);

  /// Reads the current `(hlc, rev)` of a row, or null when it does not exist.
  Future<CrdtStamp?> currentStamp(String table, String rowId) async {
    final row = await one(
      'SELECT hlc, rev FROM "$table" WHERE id = ?',
      [rowId],
    );
    if (row == null) return null;
    final encoded = row.read<String?>('hlc');
    if (encoded == null) return null;
    return CrdtStamp(hlc: Hlc.parse(encoded), rev: row.read<int?>('rev') ?? 1);
  }

  /// Refuses a write whose causal stamp is not newer than what is stored.
  ///
  /// This is the *pre-flight* half of last-write-wins. The resolver in
  /// `lib/core/crdt/lww.dart` handles the same question for data arriving from
  /// a peer; this one handles the local case, where a stale in-memory edit
  /// (a form left open for two hours, an undo stack replayed late) would
  /// otherwise silently lose to a newer change made on another device — and the
  /// user would see their edit vanish with no explanation.
  ///
  /// Throwing beats overwriting: the UI can then show both versions and ask.
  Future<void> assertFresh(String table, String rowId, CrdtStamp incoming) async {
    final current = await currentStamp(table, rowId);
    if (current == null) return;
    if (incoming < current) {
      throw InvariantViolation(
        invariantCode: 'CRDT-STALE',
        message: 'this record was changed elsewhere after you opened it '
            '(stored ${current.hlc.encode()}, your edit is ${incoming.hlc.encode()}). '
            'Reload to see the newer version before saving.',
      );
    }
  }

  /// Appends the change to `oplog` so peers can be offered it.
  ///
  /// `op` is 1 (upsert), 2 (tombstone) or 3 (immutable append-only row), matching
  /// the CHECK in `003_crdt_sync.sql`. Dispatch is deliberately **not** recorded
  /// here: `dispatched_at` stays NULL until a transport actually hands the row
  /// over, so a crash between commit and send costs nothing.
  Future<void> enqueueOplog({
    required String table,
    required String rowId,
    required int op,
    required CrdtStamp stamp,
    String? payloadJson,
    int rev = 1,
  }) async {
    // `WHERE NOT EXISTS` makes the queue idempotent per
    // (table, row, hlc, op) — an op is a statement about one row at one logical
    // instant, so the same tuple can never legitimately differ. Re-applying a
    // peer batch (dropped WebRTC chunk, retried sync) therefore cannot flood the
    // queue with duplicates, and (being one statement) it cannot race with
    // itself either: the DAOs share one serialized connection.
    await exec(
      'INSERT INTO oplog (table_name, row_id, op, hlc, node_id, ledger_id, rev, '
      'payload_json, byte_size, created_at) '
      'SELECT ?, ?, ?, ?, ?, ?, ?, ?, ?, ? '
      "WHERE NOT EXISTS (SELECT 1 FROM oplog WHERE table_name = ? AND row_id = ? "
      'AND op = ? AND hlc = ?)',
      [
        table,
        rowId,
        op,
        stamp.hlc.encode(),
        nodeId,
        ledgerId,
        rev,
        payloadJson,
        payloadJson?.length ?? 0,
        DateTime.now().millisecondsSinceEpoch,
        table,
        rowId,
        op,
        stamp.hlc.encode(),
      ],
    );
  }

  /// Appends one hash-chained audit record.
  ///
  /// `hash_self = SHA-256(hash_prev ‖ canonical_json(event))`, where the event
  /// JSON is the same canonical form the CRDT compares payloads with — sorted
  /// keys, no doubles. Because `hash_prev` is the previous record's `hash_self`
  /// for this ledger, editing or removing any record breaks the chain at the
  /// next one (contract H3), and a forged chain would have to be re-hashed all
  /// the way forward *and* carried to every peer.
  Future<void> appendAudit({
    required String action,
    required String entityType,
    String? entityId,
    Map<String, Object?>? before,
    Map<String, Object?>? after,
    String? actorName,
  }) async {
    final now = DateTime.now().millisecondsSinceEpoch;
    final seq = await scalarInt(
      'SELECT COALESCE(MAX(seq), 0) + 1 FROM audit_log WHERE ledger_id = ?',
      [ledgerId],
    );
    final previous = await scalarString(
      'SELECT hash_self FROM audit_log WHERE ledger_id = ? ORDER BY seq DESC LIMIT 1',
      [ledgerId],
    );
    final hashPrev = previous ?? '0' * 64;

    final event = <String, Object?>{
      'action': action,
      'ledger_id': ledgerId,
      'entity_id': entityId,
      'entity_type': entityType,
      'node_id': nodeId,
      'seq': seq,
      'at': now,
    };
    final hashSelf = sha256Hex([
      ...utf8Encode(hashPrev),
      ...utf8Encode(canonicalJson(event)),
    ]);

    final stamp = newStamp();
    await exec(
      'INSERT INTO audit_log (id, ledger_id, seq, actor_node_id, actor_name, action, '
      'entity_type, entity_id, before_json, after_json, hash_prev, hash_self, hlc, '
      'node_id, created_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)',
      [
        newRowId(),
        ledgerId,
        seq,
        nodeId,
        actorName,
        action,
        entityType,
        entityId,
        before == null ? null : canonicalJson(before),
        after == null ? null : canonicalJson(after),
        hashPrev,
        hashSelf,
        stamp.hlc.encode(),
        nodeId,
        now,
      ],
    );
  }

  /// Records one merge receipt (an overwritten value worth showing the user).
  ///
  /// `INSERT OR IGNORE` against `ux_conflict_receipt` (migrations/009): the
  /// receipt's identity is `(row, field, losing stamp)`, so re-applying the same
  /// batch — which the protocol does freely and on purpose — cannot fill the
  /// review queue with duplicates.
  /// Records a merge receipt — **idempotently**.
  ///
  /// The id is derived from the conflict's content, not generated, so applying
  /// the same peer batch twice (a re-sync after a dropped connection, a retried
  /// WebRTC chunk, a restored backup) writes the receipt once. A random id would
  /// make `INSERT OR IGNORE` a no-op and leave the user staring at two copies of
  /// every conflict in the review list.
  Future<void> recordConflict(FieldConflict conflict) {
    final localIsWinner = conflict.resolution == 'local_won' ||
        conflict.resolution == 'kept_local_ambiguous';
    return exec(
        'INSERT OR IGNORE INTO conflict_log (id, ledger_id, table_name, row_id, '
        'field_name, kind, local_hlc, remote_hlc, local_node, remote_node, '
        'local_json, remote_json, resolution, detected_at) '
        'VALUES (?, ?, ?, ?, ?, 1, ?, ?, ?, ?, ?, ?, ?, ?)',
        [
          // The id names the *conflict*, not the recording device: the pair of
          // versions that disagreed plus the field they disagreed about. Two
          // phones describing the same disagreement therefore write one receipt
          // between them, in either sync direction, however many times the batch
          // is replayed. Including `resolution` here would break that, because
          // the same pair reads as `remote_won` on one device and `local_won` on
          // the other — two rows for one fact, which is exactly what the review
          // list cannot survive.
          contentId('conflict', [
            conflict.tableName ?? '',
            conflict.rowId,
            conflict.field,
            conflict.loserHlc,
            conflict.winnerHlc,
          ]),
          ledgerId,
          conflict.tableName,
          conflict.rowId,
          conflict.field,
          // `local_*` is the version that was already on this device and
          // `remote_*` is the one that arrived — the schema's meaning, restored.
          // The resolver hands back the *loser* and *winner* instead, so the
          // perspective is recovered from which side won: if the local copy won,
          // the local columns hold the winner.
          localIsWinner ? conflict.winnerHlc : conflict.loserHlc,
          localIsWinner ? conflict.loserHlc : conflict.winnerHlc,
          localIsWinner ? conflict.winnerNode : conflict.loserNode,
          localIsWinner ? conflict.loserNode : conflict.winnerNode,
          canonicalJson(localIsWinner ? conflict.winnerValue : conflict.loserValue),
          canonicalJson(localIsWinner ? conflict.loserValue : conflict.winnerValue),
          conflict.resolution,
          DateTime.now().millisecondsSinceEpoch,
        ],
      );
  }

  /// Allocates the next document/entry number for this ledger **and this node**.
  ///
  /// Keyed by `(ledger_id, doc_kind, node_id)` so two devices offline at the same
  /// time can both number an invoice 0001 without colliding — the numbers are
  /// per-device sequences, and the *document identity* is the UUID, never the
  /// human number. Duplicate human numbers across devices are surfaced as a
  /// `duplicate_document` conflict (kind 2 in `conflict_log`) for the user to
  /// renumber, which is the honest handling: silently renumbering someone's
  /// invoice is worse than asking.
  Future<String> nextNumber(int docKind, {String? prefix, int padding = 4}) async {
    final effectivePrefix = prefix ?? DocKind.prefixes[docKind] ?? 'DOC';
    await exec(
      'INSERT OR IGNORE INTO number_sequences (ledger_id, doc_kind, node_id, prefix, '
      'padding, next_value, step) VALUES (?, ?, ?, ?, ?, 1, 1)',
      [ledgerId, docKind, nodeId, effectivePrefix, padding],
    );
    final allocated = await scalarInt(
      'UPDATE number_sequences SET next_value = next_value + step '
      'WHERE ledger_id = ? AND doc_kind = ? AND node_id = ? '
      'RETURNING next_value - step',
      [ledgerId, docKind, nodeId],
    );
    return '$effectivePrefix-${allocated.toString().padLeft(padding, '0')}';
  }

  /// A fresh UUIDv7, the primary key of every replicated row.
  ///
  /// Time-ordered, so primary keys sort chronologically — which keeps B-tree
  /// inserts append-mostly (measurable: the benchmark's write path) and lets a
  /// backup pack restore rows in insertion order.
  String newRowId() => newUuidV7();

  /// Maps a SQLite failure to the app's typed errors.
  ///
  /// The triggers raise messages that start with a stable code (`INT-5b:`,
  /// `DOC-3:`, `INTEGRITY GATE:`); translating here means no UI code ever
  /// string-matches, and a trigger message can change without a hunt.
  Never mapSqliteError(Object error, StackTrace stackTrace) {
    // InvariantViolation.tryParse recognises the whole INT-/DOC-/FIN-/GATE
    // code family the schema raises, so a new trigger needs no change here.
    final invariant = InvariantViolation.tryParse(error);
    if (invariant != null) throw invariant;
    if (error is SqliteException &&
        (error.message.contains('immutable') || error.message.contains('read-only'))) {
      throw const ImmutableDocumentException(documentNo: '', field: 'entry');
    }
    Error.throwWithStackTrace(error, stackTrace);
  }
}

/// A **content-addressed** id: same inputs, same id, forever.
///
/// Used where a row is a *receipt* rather than an entity — merge conflict
/// records today, applied-sync markers and backup pack manifests next. A UUIDv7
/// is right for an entity (it sorts by creation) and wrong for a receipt (a
/// retry must land on the row that is already there). The 36-character shape and
/// a UUID version nibble are kept so the schema's `CHECK (length(id) = 36)` holds
/// and the value is indistinguishable from any other id in a backup pack.
String contentId(String namespace, List<String> parts) {
  final digest = sha256(utf8.encode('$namespace\u0000${parts.join('\u0000')}'));
  final hex = [for (final byte in digest) byte.toRadixString(16).padLeft(2, '0')].join();
  return '${hex.substring(0, 8)}-${hex.substring(8, 12)}-5${hex.substring(13, 16)}'
      '-8${hex.substring(17, 20)}-${hex.substring(20, 32)}';
}

/// A monotonically-ordered UUIDv7 (RFC 9562): 48-bit millisecond timestamp,
/// version/variant bits, then randomness.
///
/// Not `package:uuid`'s v7 because this one must be *dependency-free* (the key
/// path already needs to run in a bare Dart process) and because we want the
/// whole id to remain lexicographically ordered as a string, which is what makes
/// `ORDER BY id` equivalent to insertion order.
String newUuidV7({int? timestampMs, List<int>? random}) {
  final now = timestampMs ?? DateTime.now().millisecondsSinceEpoch;
  final bytes = List<int>.filled(16, 0);

  bytes[0] = (now >> 40) & 0xFF;
  bytes[1] = (now >> 32) & 0xFF;
  bytes[2] = (now >> 24) & 0xFF;
  bytes[3] = (now >> 16) & 0xFF;
  bytes[4] = (now >> 8) & 0xFF;
  bytes[5] = now & 0xFF;

  final source = random ?? randomBytes(10);
  for (var i = 0; i < 10; i++) {
    bytes[6 + i] = source[i];
  }
  bytes[6] = (bytes[6] & 0x0F) | 0x70; // version 7
  bytes[8] = (bytes[8] & 0x3F) | 0x80; // RFC 4122 variant

  final hex = bytes.map((b) => b.toRadixString(16).padLeft(2, '0')).join();
  return '${hex.substring(0, 8)}-${hex.substring(8, 12)}-${hex.substring(12, 16)}'
      '-${hex.substring(16, 20)}-${hex.substring(20)}';
}

  /// Posts a draft. This is the only path to `status = 1`, and
  /// `trg_je_balance_gate` is the authority on whether it is allowed.
  ///
  /// The totals are written in the same UPDATE that flips the status, so the
  /// trigger sees the values the entry will have. If the gate refuses, SQLite
  /// aborts the statement and the caller's transaction rolls back — the entry
  /// stays a draft, which is the correct state for "not yet valid".
  Future<PostedEntry> post(String entryId, {CrdtStamp? expecting}) async {
    if (expecting != null) {
      await assertFresh('journal_entries', entryId, expecting);
    }
    final now = DateTime.now().millisecondsSinceEpoch;
    final stamp = newStamp();

    try {
      await exec(
        'UPDATE journal_entries SET status = 1, posted_at = ?, '
        'total_debit_minor = (SELECT COALESCE(SUM(CASE WHEN amount_minor > 0 '
        '  THEN amount_minor ELSE 0 END), 0) FROM journal_lines WHERE entry_id = ?), '
        'total_credit_minor = (SELECT COALESCE(SUM(CASE WHEN amount_minor < 0 '
        '  THEN -amount_minor ELSE 0 END), 0) FROM journal_lines WHERE entry_id = ?), '
        // NOTE the semantics: `total_debit_minor`/`total_credit_minor` are the
        // one-sided totals (each equal to the entry's value), while
        // `base_total_minor` is the GROSS sum of absolute base amounts — twice
        // the value for a two-line entry. That asymmetry is what
        // `008_integrity.sql`'s ENTRY_TOTALS_DRIFT check asserts, and writing
        // the halved figure here is exactly what this DB's own audit gate caught
        // during development.
        'base_total_minor = (SELECT COALESCE(SUM(ABS(base_amount_minor)), 0) '
        '  FROM journal_lines WHERE entry_id = ?), '
        'hlc = ?, node_id = ?, rev = rev + 1, updated_at = ? '
        'WHERE id = ? AND ledger_id = ?',
        [now, entryId, entryId, entryId, stamp.hlc.encode(), nodeId, now, entryId, ledgerId],
      );
    } on Object catch (error, stackTrace) {
      mapSqliteError(error, stackTrace);
    }

    // The op carries the rev the row now has, not the default 1: a peer that
    // applies it must land on the same `(hlc, rev)` the row holds here, or its
    // next edit looks stale to itself.
    await enqueueOplog(
      table: 'journal_entries',
      rowId: entryId,
      op: 1,
      stamp: stamp,
      rev: await scalarInt(
        'SELECT rev FROM journal_entries WHERE id = ?',
        [entryId],
      ),
      payloadJson: canonicalJson({'id': entryId, 'status': 1, 'posted_at': now}),
    );
    await appendAudit(
      action: 'entry.posted',
      entityType: 'journal_entry',
      entityId: entryId,
      after: {'status': 1, 'posted_at': now},
    );

    return (await findById(entryId))!;
  }

  /// Voids a posted entry by writing its **reversal** rather than deleting it.
  ///
  /// A ledger that can forget is not a ledger. The original stays, marked
  /// voided, and a mirror-image entry (source `reversal`) puts the balances
  /// back; `journal_entries.reversal_of_entry_id` links them, so "why is this
  /// month different from what I saw last week?" is answerable forever.
  /// Undoes a posted entry — by **voiding** it, or by **reversing** it.
  ///
  /// These are not two spellings of one thing, and this database says so:
  /// `trg_bal_void` removes a voided entry's money from every cached balance the
  /// moment `status` becomes 2. Posting a mirror entry *and* flipping the status
  /// therefore subtracts the same rupees twice, which is precisely what the
  /// commit gate caught while this method was being written.
  ///
  /// * `reverse == false` — **void**. `status = 2`, `voided_at` stamped, money
  ///   gone from reports, the entry itself kept for audit (`trg_je_no_delete`
  ///   forbids deleting it). This is "I typed that sale wrong", same period.
  /// * `reverse == true` — **reversal**. A new entry that mirrors the original
  ///   with every amount negated, dated [reverseDate] (default: the original's
  ///   date). The original is untouched, so a filed period keeps its books and
  ///   the offset lands in the period you are actually working in. This is a
  ///   customer credit note, or a correction to a locked period.
  ///
  /// Both are single transactions: status, stamp, op-log row and audit row
  /// either all land or none do.
  Future<VoidOutcome> voidEntry(
    String entryId, {
    required String reason,
    bool reverse = false,
    DateTime? reverseDate,
  }) async {
    final original = await one(
      'SELECT entry_date, source, currency_code, fx_rate_micros, party_id, doc_no '
      'FROM journal_entries WHERE id = ? AND ledger_id = ? AND status = 1',
      [entryId, ledgerId],
    );
    if (original == null) {
      throw InvariantViolation(
        invariantCode: 'INT-3',
        message: 'only a posted entry can be voided (entry $entryId is absent, a '
            'draft, or already voided)',
      );
    }
    final originalDate = original.read<int>('entry_date');

    if (!reverse) {
      // Void: one status transition. The cache follows by trigger, the CRDT
      // stamp moves so the cancellation reaches other devices, and the audit
      // chain records who did it and why.
      final stamp = newStamp();
      final now = DateTime.now().millisecondsSinceEpoch;
      final confirmed = await scalarInt(
        'UPDATE journal_entries SET status = 2, voided_at = ?, hlc = ?, rev = rev + 1, '
        'updated_at = ? WHERE id = ? AND ledger_id = ? AND status = 1 RETURNING rev',
        [now, stamp.hlc.encode(), now, entryId, ledgerId],
      );
      if (confirmed == 0) {
        throw InvariantViolation(
          invariantCode: 'INT-3',
          message: 'entry $entryId was already voided by someone else',
        );
      }
      await enqueueOplog(
        table: 'journal_entries',
        rowId: entryId,
        op: 3, // tombstone: an observer must remove it, not overwrite it
        stamp: stamp,
        rev: confirmed,
        payloadJson: canonicalJson({'id': entryId, 'status': 2, 'reason': reason}),
      );
      await appendAudit(
        action: 'entry.voided',
        entityType: 'journal_entry',
        entityId: entryId,
        before: {'status': 1},
        after: {'status': 2, 'voided_at': now, 'reason': reason},
      );
      return VoidOutcome(
        entryId: entryId,
        mode: VoidMode.voided,
        entryDate: originalDate,
        voidedAt: now,
      );
    }

    // Reversal: the mirror image, posted like any other entry so the balance
    // gate, the cache accrual and the op log all run exactly once, normally.
    final lines = await all(
      'SELECT account_id, party_id, -amount_minor AS amount_minor, -base_amount_minor '
      'AS base_amount_minor, currency_code, item_id, -quantity_milli AS quantity_milli, '
      'unit_cost_micros, memo FROM journal_lines WHERE entry_id = ? ORDER BY line_no',
      [entryId],
    );
    final onDate = reverseDate == null
        ? originalDate
        : EpochDay.fromDateTime(reverseDate);

    final mirror = EntryDraft(
      entryDate: onDate,
      source: LedgerSource.reversal,
      partyId: original.read<String?>('party_id'),
      docNo: original.read<String?>('doc_no'),
      currencyCode: original.read<String>('currency_code'),
      fxRateMicros: original.read<int>('fx_rate_micros'),
      memo: 'Reversal of entry $entryId — $reason',
      lines: [
        for (final line in lines)
          JournalLineDraft(
            accountId: line.read<String>('account_id'),
            partyId: line.read<String?>('party_id'),
            amountMinor: line.read<int>('amount_minor'),
            itemId: line.read<String?>('item_id'),
            quantityMilli: line.read<int>('quantity_milli'),
            unitCostMicros: line.read<int>('unit_cost_micros'),
            memo: line.read<String?>('memo'),
          ),
      ],
    );

    final mirrorId = await insertDraft(mirror);
    await exec(
      'UPDATE journal_entries SET reversal_of_entry_id = ? WHERE id = ?',
      [entryId, mirrorId],
    );
    final posted = await post(mirrorId);
    await appendAudit(
      action: 'entry.reversed',
      entityType: 'journal_entry',
      entityId: entryId,
      before: {'status': 1},
      after: {
        'reversal_entry_id': posted.entryId,
        'reversal_entry_no': posted.entryNo,
        'reversal_date': onDate,
        'reason': reason,
      },
    );
    return VoidOutcome(
      entryId: entryId,
      mode: VoidMode.reversed,
      entryDate: originalDate,
      mirrorEntryId: posted.entryId,
      mirrorEntryNo: posted.entryNo,
    );
  }

  /// Multiplies a signed amount back onto an account's normal side, for display.
  ///
  /// A raw `net_minor` is debit-positive, which is right for the database and
  /// confusing for a human looking at a liabilities column. Reports multiply by

  static int onNormalSide(int netMinor, int normalBalance) => netMinor * normalBalance;

  int _baseAmount(int amountMinor, int fxRateMicros) {
    if (fxRateMicros == 1000000) return amountMinor;
    final scaled = BigInt.from(amountMinor) * BigInt.from(fxRateMicros) +

  /// anything that gets overwritten.
  ///

  /// refused (`assertFresh`). A form that has been open for an hour must not
  /// silently clobber a phone number the owner typed on the other phone.

    CrdtStamp? expecting,

    return inTransaction(() async {
      final existing = await one(

          invariantCode: 'INT-7',

      if (current == null) {
        throw InvariantViolation(
          invariantCode: 'INT-7',
          message: 'party $partyId has no causal stamp; the row is corrupt',
        );
      }
      if (expecting != null && expecting < current) {
        throw const InvariantViolation(
          invariantCode: 'CRDT-STALE',
          message: 'this party was changed elsewhere after you opened it. '
              'Reload to see the newer version before saving.',

      final assignments = <String>[];
      final values = <Object?>[];

        assignments.add('${entry.key} = ?');
        values.add(entry.value);
      }
      await exec(
        'UPDATE parties SET ${assignments.join(', ')}, hlc = ?, node_id = ?, rev = rev + 1, '
        'updated_at = ? WHERE id = ? AND ledger_id = ?',

      );

/// KhataPro · the order book: every business action, as one checked transaction.
///
/// This is the layer the UI talks to. A screen never writes SQL; it calls a
/// method here that describes a *business event* ("a sale of Rs 1,250 with 18%
/// tax, half paid in cash, on credit for the rest") and returns a receipt or a
/// typed refusal.
///
/// ## `commitChecked`
///
/// Every write goes through [commitChecked], which is the answer to a specific
/// worry: *"if the database is the only source of truth and there is no server
/// to reconcile against, what stops one bad write from silently corrupting the
/// books?"*
///
/// Three layers already guard the write path, at increasing cost:
///
///   1. **CHECK constraints, STRICT tables, foreign keys** — free. Types cannot
///      lie, money cannot be a float, a line cannot point at another ledger.
///   2. **Triggers** — the balance gate, immutability, period locks, the cache
///      accrual. These run *inside* the write, so a refusal aborts the statement.
///   3. **`commitChecked`** — after the statements, before the commit is made
///      visible, it re-reads the *audited* state and rolls the transaction back
///      if anything critical appeared. This catches the class of bug the first
///      two cannot: an error in the application's own arithmetic, or a cache that
///      drifted one row behind.
///
/// The cost is real (it is a query, not a rubber stamp), so there are two modes:
/// [CommitCheck.quick] verifies only what this transaction touched — a few
/// index lookups — and [CommitCheck.full] runs the whole audited report. The
/// defaults are chosen per operation: posting money uses `quick`, and anything
/// that rewrites history (voiding, opening balances, a restore) uses `full`.

final class OrderBook {
  OrderBook({required this.db, required this.ledgerId}) : _accounts = AccountsDao(db: db, ledgerId: ledgerId) {
    _journal = JournalDao(db: db, ledgerId: ledgerId);
  }

  final KhataDatabase db;
  final String ledgerId;
  final AccountsDao _accounts;
  late final JournalDao _journal;

  JournalDao get journal => _journal;
  AccountsDao get accounts => _accounts;

  // ───────────────────────────────────────────────────────────────────────────
  //  The gate
  // ───────────────────────────────────────────────────────────────────────────

  /// Runs [work] in one transaction and refuses to commit a book that has
  /// become inconsistent.
  ///
  /// Rolling back on a *newly appeared* critical finding is the whole idea: a
  /// shopkeeper would rather be told "this entry was not saved because it would
  /// have broken the books" than find out a month later that the trial balance
  /// stopped adding up. The findings are read back **inside** the transaction
  /// (same connection, so it sees uncommitted rows) and the refusal throws, which
  /// makes drift roll back.
  Future<(T, CommitReport)> commitChecked<T>(
    Future<T> Function() work, {
    CommitCheck check = CommitCheck.quick,
    Set<String> touchedAccountIds = const {},
  }) async {
    final started = DateTime.now();
    return inTransaction(() async {
      final result = await work();

      final findings = check == CommitCheck.full
          ? await db.integrityReport()
          : await _quickFindings(touchedAccountIds);

      final report = CommitReport(
        mode: check,
        durationMs: DateTime.now().difference(started).inMilliseconds,
        accountsChecked: touchedAccountIds.length,
        findings: findings,
      );

      final critical = findings.where((f) => f.isCritical).toList();
      if (critical.isNotEmpty) {
        throw InvariantViolation(
          invariantCode: 'GATE-2',
          message: 'the write was rolled back because it would have left the books '
              'inconsistent: ${critical.first.detail} '
              '(${critical.length} critical finding${critical.length == 1 ? '' : 's'})',
        );
      }
      return (result, report);
    });
  }

  Future<T> inTransaction<T>(Future<T> Function() work) => db.transaction(() => work());

  /// The cheap half of the audit: the checks a single posting could plausibly
  /// break, evaluated only where the posting went.
  ///
  ///   · the entry balances, has both sides, and has at least two lines;
  ///   · for each account the entry touched, the audited cache still equals the
  ///     live sum of its lines (`v_account_balances` vs `v_account_balances_live`).
  ///
  /// Everything else in the audited report (cross-ledger references, audit-chain
  /// integrity, orphaned allocations, stock) cannot be affected by one balanced
  /// entry, and is covered by [CommitCheck.full] and the boot-time sweep.
  Future<List<IntegrityFinding>> _quickFindings(Set<String> accountIds) async {
    final findings = <IntegrityFinding>[];

    final unbalanced = await db.customSelect(
      "SELECT count(*) AS n FROM v_integrity_report WHERE severity = 1 "
      "AND kind IN ('UNBALANCED_ENTRY','PARENT_POSTING','CROSS_LEDGER_LINE')",
    ).get();
    final count = unbalanced.first.read<int>('n');
    if (count > 0) {
      findings.add(IntegrityFinding(
        severity: 1,
        kind: 'UNBALANCED_ENTRY',
        detail: '$count critical finding(s) of a kind this transaction could have caused',
      ));
    }

    if (accountIds.isNotEmpty) {
      final placeholders = List.filled(accountIds.length, '?').join(', ');
      final drift = await db.customSelect(
        'SELECT c.account_id, c.net_minor AS cached, l.net_minor AS live '
        'FROM v_account_balances c '
        'JOIN v_account_balances_live l '
        '  ON l.ledger_id = c.ledger_id AND l.account_id = c.account_id '
        'WHERE c.ledger_id = ? AND c.account_id IN ($placeholders) '
        '  AND c.net_minor <> l.net_minor',
        variables: [Variable<String>(ledgerId), ...[for (final id in accountIds) Variable<String>(id)]],
      ).get();
      for (final row in drift) {
        findings.add(IntegrityFinding(
          severity: 1,
          kind: 'CACHE_DRIFT',
          detail: 'balance cache for account ${row.read<String>('account_id')} reads '
              '${row.read<int>('cached')} while its lines sum to ${row.read<int>('live')}',
          entityId: row.read<String>('account_id'),
        ));
      }
    }

    return findings;
  }

  // ───────────────────────────────────────────────────────────────────────────
  //  Business events
  // ───────────────────────────────────────────────────────────────────────────

  /// A sale. Cash and credit at once, tax included, cost of goods if the items
  /// are stocked.
  ///
  /// The lines it writes, in the schema's signed convention (debit positive):
  ///
  ///   ```text
  ///   Dr  1100 Cash                 amountPaid         (only what was received)
  ///   Dr  1200 · party  (AR)        onCredit           (only if part was unpaid)
  ///   Cr  4100 Sales                netOfTax
  ///   Cr  2300 Tax payable          taxMinor           (only if tax > 0)
  ///   Dr  5100 COGS                 cogsMinor          (only if stocked goods)
  ///   Cr  1300 Inventory            cogsMinor
  ///   ```
  ///
  /// Note what is *not* here: no "discount" fudge line and no rounding plug. If
  /// the caller's numbers do not add up, the entry is refused with the exact
  /// difference — the shopkeeper fixes the invoice, and the books never carry a
  /// mystery cent.
  Future<OrderReceipt> postSale({
    required int entryDate,
    required int grossMinor,
    required int amountPaidMinor,
    int taxMinor = 0,
    int cogsMinor = 0,
    String? partyId,
    String? docNo,
    String? memo,
    String currencyCode = 'PKR',
    CommitCheck check = CommitCheck.quick,
  }) async {
    if (grossMinor <= 0) {
      throw const InvariantViolation(
        invariantCode: 'FIN-1',
        message: 'a sale must be for a positive amount',
      );
    }
    if (amountPaidMinor < 0 || amountPaidMinor > grossMinor) {
      throw const InvariantViolation(
        invariantCode: 'FIN-1',
        message: 'the amount received must be between zero and the invoice total',
      );
    }
    final onCredit = grossMinor - amountPaidMinor;
    if (onCredit > 0 && partyId == null) {
      throw const InvariantViolation(
        invariantCode: 'FIN-2',
        message: 'an unpaid sale needs a customer, or there is nobody to recover '
            'it from',
      );
    }

    final lines = <JournalLineDraft>[];
    final touched = <String>{};

    if (amountPaidMinor > 0) {
      final cash = await _accounts.byRole(AccountRole.cash);
      _require(cash, AccountRole.cash, 'to receive the payment');
      lines.add(JournalLineDraft(
        accountId: cash!.accountId,
        amountMinor: amountPaidMinor,
        memo: 'Received',
      ));
      touched.add(cash.accountId);
    }
    if (onCredit > 0) {
      final arId = await _accounts.partyAccountId(partyId!) ??
          await _accounts.ensurePartySubledger(partyId, controlRole: AccountRole.ar);
      _require(await _accounts.byId(arId), AccountRole.ar, 'to record the unpaid part');
      lines.add(JournalLineDraft(
        accountId: arId,
        amountMinor: onCredit,
        partyId: partyId,
        memo: 'On credit',
      ));
      touched.add(arId);
    }

    // Income is the gross minus the tax that must be handed over; the tax line
    // is informational on the item but authoritative here.
    final netOfTax = grossMinor - taxMinor;
    final sales = await _accounts.byRole(AccountRole.sales);
    _require(sales, AccountRole.sales, 'to record the income');
    lines.add(JournalLineDraft(
      accountId: sales!.accountId,
      amountMinor: -netOfTax,
      memo: memo ?? 'Sale',
    ));
    touched.add(sales.accountId);

    if (taxMinor > 0) {
      final tax = await _accounts.byRole(AccountRole.taxPayable);
      _require(tax, AccountRole.taxPayable, 'to record the tax collected');
      lines.add(JournalLineDraft(
        accountId: tax!.accountId,
        amountMinor: -taxMinor,
        taxMinor: taxMinor,
        taxBaseMinor: netOfTax,
        memo: 'Sales tax collected',
      ));
      touched.add(tax.accountId);
    }

    if (cogsMinor > 0) {
      final cogs = await _accounts.byRole(AccountRole.cogs);
      final inventory = await _accounts.byRole(AccountRole.inventory);
      _require(cogs, AccountRole.cogs, 'to record the cost of what was sold');
      _require(inventory, AccountRole.inventory, 'to relieve the stock of what was sold');
      lines
        ..add(JournalLineDraft(
          accountId: cogs!.accountId,
          amountMinor: cogsMinor,
          memo: 'Cost of goods sold',
        ))
        ..add(JournalLineDraft(
          accountId: inventory!.accountId,
          amountMinor: -cogsMinor,
          memo: 'Stock out',
        ));
      touched
        ..add(cogs.accountId)
        ..add(inventory.accountId);
    }

    final draft = EntryDraft(
      entryDate: entryDate,
      source: LedgerSource.sale,
      lines: lines,
      memo: memo ?? 'Sale',
      docNo: docNo,
      partyId: partyId,
      currencyCode: currencyCode,
    );

    // Balance in Dart first, so the common mistake (a UI that rounded one leg)
    // produces a message naming the amounts rather than the trigger's code.
    if (draft.balanceMinor != 0) {
      throw UnbalancedEntryException(
        debitTotal: draft.totalDebitMinor,
        creditTotal: draft.totalCreditMinor,
        entryId: '(new sale)',
        lineCount: lines.length,
      );
    }

    final (posted, report) = await commitChecked(
      () => _journal.writeAndPost(draft),
      check: check,
      touchedAccountIds: touched,
    );
    return OrderReceipt(
      entryId: posted.entryId,
      entryNo: posted.entryNo,
      totalMinor: grossMinor,
      commit: report,
      partyId: partyId,
      memo: draft.memo,
      lines: [for (final line in lines) _describe(line)],
    );
  }

  /// An expense paid from cash or bank. The simplest double entry there is, and
  /// the one a shopkeeper makes ten times a day.
  Future<OrderReceipt> postExpense({

    required int amountMinor,
    String role = AccountRole.miscExpense,
    bool fromBank = false,
    String? memo,

      throw const InvariantViolation(
        invariantCode: 'FIN-1',
        message: 'an expense must be for a positive amount',
      );
    }
    final expense = await _accounts.byRole(role);
    _require(expense, role, 'to record this kind of expense');
    final source = await _accounts.byRole(fromBank ? AccountRole.bank : AccountRole.cash);
    _require(source, fromBank ? AccountRole.bank : AccountRole.cash, 'to pay from');

    final draft = EntryDraft(
      entryDate: entryDate,
      source: LedgerSource.expense,
      memo: memo,
      docNo: docNo,
      lines: [
        JournalLineDraft(accountId: expense!.accountId, amountMinor: amountMinor, memo: memo),
        JournalLineDraft(accountId: source!.accountId, amountMinor: -amountMinor),
      ],
    );

    final (posted, report) = await commitChecked(
      () => _journal.writeAndPost(draft),
      check: check,
      touchedAccountIds: {expense.accountId, source.accountId},
    );
    return OrderReceipt(
      entryId: posted.entryId,
      entryNo: posted.entryNo,
      totalMinor: amountMinor,
      commit: report,
      memo: memo,
    );
  }

  /// Money received from a customer against what they owe.
  ///
  /// A payment settles a *balance*, not an invoice — invoice-level allocation
  /// lives in `payment_allocations` and is applied by the documents layer (D3),
  /// because "which bill did this clear?" is a question the user answers, not
  /// one the arithmetic can assume. Until then the money still lands correctly:
  /// cash up, receivable down.
  Future<OrderReceipt> postPaymentIn({
    required int entryDate,
    required int amountMinor,
    required String partyId,
    bool toBank = false,
    String? memo,
    CommitCheck check = CommitCheck.quick,
  }) async {
    if (amountMinor <= 0) {
      throw const InvariantViolation(
        invariantCode: 'FIN-1',
        message: 'a payment must be for a positive amount',
      );
    }
    final destination = await _accounts.byRole(toBank ? AccountRole.bank : AccountRole.cash);
    _require(destination, toBank ? AccountRole.bank : AccountRole.cash, 'to receive into');
    final arId = await _accounts.partyAccountId(partyId) ??
        await _accounts.ensurePartySubledger(partyId, controlRole: AccountRole.ar);

    final draft = EntryDraft(
      entryDate: entryDate,
      source: LedgerSource.paymentIn,
      memo: memo ?? 'Payment received',
      partyId: partyId,
      lines: [
        JournalLineDraft(
          accountId: destination!.accountId,
          amountMinor: amountMinor,
          memo: 'Received',
        ),
        JournalLineDraft(
          accountId: arId,
          amountMinor: -amountMinor,
          partyId: partyId,
          memo: 'Against balance',
        ),
      ],
    );

    final (posted, report) = await commitChecked(
      () => _journal.writeAndPost(draft),
      check: check,
      touchedAccountIds: {destination.accountId, arId},
    );
    return OrderReceipt(
      entryId: posted.entryId,
      entryNo: posted.entryNo,
      totalMinor: amountMinor,
      commit: report,
      partyId: partyId,
      memo: draft.memo,
    );
  }

  /// Writes an opening balance for an account (the shop's cash in the drawer on
  /// the day it started using the app).
  ///
  /// Uses the full sweep: opening balances are the one write where a mistake is
  /// both easy and invisible (it is the base every later number is measured
  /// from), and they happen once per book, so paying ~275 ms is free.
  Future<OrderReceipt> postOpening({
    required int entryDate,
    required List<(String role, int amountMinor)> balances,
    String? memo,
  }) async {
    final lines = <JournalLineDraft>[];
    final touched = <String>{};
    var total = 0;
    for (final (role, amount) in balances) {
      if (amount == 0) continue;
      final account = await _accounts.byRole(role);
      _require(account, role, 'to record its opening balance');
      lines.add(JournalLineDraft(
        accountId: account!.accountId,
        amountMinor: amount,
        memo: 'Opening balance',
        isOpening: true,
      ));
      touched.add(account.accountId);
      total += amount;
    }
    if (lines.length < 2) {
      throw UnbalancedEntryException(
        debitTotal: total,
        creditTotal: 0,
        entryId: '(opening balances)',
        lineCount: lines.length,
      );
    }

    final equity = await _accounts.byRole(AccountRole.openingEquity);
    _require(equity, AccountRole.openingEquity, 'to balance the opening entry');
    // Whatever the assets/liabilities do not account for is the owner's equity
    // at the moment the books open — the plug, in the one place a plug is
    // legitimate, and visible as its own line.
    lines.add(JournalLineDraft(
      accountId: equity!.accountId,
      amountMinor: -total,
      memo: 'Opening equity',
      isOpening: true,
    ));
    touched.add(equity.accountId);

    final draft = EntryDraft(
      entryDate: entryDate,
      source: LedgerSource.opening,
      memo: memo ?? 'Opening balances',
      lines: lines,
    );

    final (posted, report) = await commitChecked(
      () => _journal.writeAndPost(draft),
      check: CommitCheck.full,
      touchedAccountIds: touched,
    );
    return OrderReceipt(
      entryId: posted.entryId,
      entryNo: posted.entryNo,
      totalMinor: total,
      commit: report,
      memo: draft.memo,
    );
  }

  /// Voids a posted entry by writing its reversal. `full` by default: undoing
  /// something is exactly when you want the whole book re-checked.
  /// Undoes a posted entry, choosing the mechanism the books require.
  ///
  /// * Period still open → **void** (`status = 2`): the money leaves every
  ///   report, the row stays for audit.
  /// * Period locked (`ledgers.lock_after_date`) → **reversal**: a negated mirror
  ///   entry dated today, because erasing rupees from a filed period would
  ///   silently change a return that has already been submitted.
  ///
  /// Pass [mode] to override (e.g. a shopkeeper who wants a credit note even
  /// though the period is open). The receipt always says which happened.
  Future<VoidReceipt> voidEntry(
    String entryId, {
    required String reason,
    VoidMode? mode,
  }) async {
    final entry = await _journal.findById(entryId);
    if (entry == null) {
      throw InvariantViolation(
        invariantCode: 'INT-3',
        message: 'no entry $entryId in this book — nothing to undo',
      );
    }
    final lockAfter = await _accounts.scalarInt(
      'SELECT COALESCE(lock_after_date, 0) FROM ledgers WHERE id = ?',
      [ledgerId],
    );
    final isLocked = lockAfter > 0 && entry.entryDate <= lockAfter;
    final chosen = mode ?? (isLocked ? VoidMode.reversed : VoidMode.voided);

    // A reversal must land on an **open** day. `trg_je_locked_period` refuses to
    // post anything dated `<= lock_after_date`, and "closed through today" is a
    // lock whose window includes today — so the first acceptable date is
    // `lock_after_date + 1`, or today when today is already past the window.
    // Dating it *after* the lock is also the honest accounting: the correction
    // belongs to the period you are working in, not to the filed one.
    final today = EpochDay.fromDateTime(DateTime.now());
    final mirrorIsPastLock = !isLocked || today > (lockAfter + 1);

    final (outcome, report) = await commitChecked(
      () => _journal.voidEntry(
        entryId,
        reason: reason,
        reverse: chosen == VoidMode.reversed,
        // A mirror must be dated outside the locked window, or `FIN-1` refuses
        // to post it — the lock is doing its job, we just have to aim at an
        // open period.
        reverseDate: chosen == VoidMode.reversed
            ? (mirrorIsPastLock
                ? DateTime.now()
                : EpochDay.toLocalMidnight(today + 1))
            : null,
      ),
      // A void moves money out of the trial balance, which is exactly the class
      // of write worth re-deriving the whole report for.
      check: CommitCheck.full,
      touchedAccountIds: const {},
    );

    return VoidReceipt(
      entryId: entryId,
      entryNo: entry.entryNo,
      totalMinor: entry.totalDebitMinor,
      commit: report,
      mode: outcome.mode,
      wasLockedPeriod: isLocked,
      reversalDate: chosen == VoidMode.reversed
          ? (mirrorIsPastLock ? today : lockAfter + 1)
          : null,
      mirrorEntryId: outcome.mirrorEntryId,
      mirrorEntryNo: outcome.mirrorEntryNo,
      memo: '${outcome.isVoid ? 'Voided' : 'Reversed'}: $reason',
    );
  }

  /// Posts a correcting mirror of [entryId] dated [date] (today by default).
  ///
  /// Kept separate from [voidEntry] because a credit note is not an undo: the
  /// shopkeeper wants the original invoice to stand and a return to be visible
  /// against it.
  Future<OrderReceipt> reverseEntry(
    String entryId, {
    required String reason,
    DateTime? date,
  }) async {
    final (outcome, report) = await commitChecked(
      () => _journal.voidEntry(
        entryId,
        reason: reason,
        reverse: true,
        reverseDate: date ?? DateTime.now(),
      ),
      check: CommitCheck.full,
      touchedAccountIds: const {},
    );
    final mirror = await _journal.findById(outcome.mirrorEntryId!);
    return OrderReceipt(
      entryId: outcome.mirrorEntryId!,
      entryNo: outcome.mirrorEntryNo ?? mirror?.entryNo ?? '(reversal)',
      totalMinor: mirror?.totalDebitMinor ?? 0,
      commit: report,
      memo: 'Reversal of ${outcome.entryId}: $reason',
    );
  }

  /// The "check my books" action, and what runs after a sync merge.
  Future<CommitReport> audit({CommitCheck check = CommitCheck.full}) async {
    final started = DateTime.now();
    final findings = await db.integrityReport();
    return CommitReport(
      mode: check,
      durationMs: DateTime.now().difference(started).inMilliseconds,
      accountsChecked: 0,
      findings: findings,
    );
  }

  /// Rewrites the audited balance cache from the journal lines.
  ///
  /// Only legitimate after a dirty open, a restore, or a sync merge — the cache
  /// is otherwise maintained by trigger. `GATE-2` re-verifies it immediately

      await db.customStatement(
          await db.assetLoader.load('assets/sql/ops/rebuild_caches.sql'));
      await db.customStatement('COMMIT');
    } on Object {
      await db.customStatement('ROLLBACK');
      rethrow;
    }
    final findings = await db.integrityReport();
    return CommitReport(
      mode: CommitCheck.full,
      durationMs: DateTime.now().difference(started).inMilliseconds,
      accountsChecked: 0,
      findings: findings,
    );
  }

  void _require(AccountBalance? account, String role, String why) {
    if (account == null || !account.isPostable) {

        message: 'this book has no postable account for "$role", so it cannot '

    }
  }

  String _describe(JournalLineDraft line) =>
      '${line.isDebit ? 'Dr' : 'Cr'} ${MoneyMinor.fromMinor(line.amountMinor.abs(), 2).format()}'
      '${line.memo == null ? '' : ' · ${line.memo}'}';
}

/// KhataPro · key derivation.
///
/// Two algorithms, on purpose:
///
///   1. **Argon2id** — the passphrase → key path. Memory-hard, GPU-hostile,
///      the 2026 default (RFC 9106). Used for the SQLCipher key and for the

/// PBKDF2-HMAC-SHA256, pure Dart.
///
/// Written from RFC 8018 / RFC 2898 §5.2. Implemented here rather than pulled
/// in as a dependency because it is ~40 lines, has published test vectors, and
/// is on the critical path of "can this user still open their books in five
/// years on a device we have never seen".
final class Pbkdf2KeyDerivation implements KeyDerivation {
  const Pbkdf2KeyDerivation();

  /// Iterations for a *portable* derivation (backup packs, legacy import).
  /// Not a substitute for Argon2id on the primary path: PBKDF2 is GPU-friendly,
  /// so it needs many more iterations for equivalent resistance, and each one
  /// costs the user's battery.
  static const int recommendedIterations = 600000;

  /// Soft cap for the pure-Dart implementation: 10 000 iterations is roughly
  /// 1 s on a mid-range phone. Above this, use the native path.
  static const int portableIterations = 10000;

  static const KdfParams portableParams = KdfParams(
    algorithm: 'pbkdf2-hmac-sha256',
    iterations: portableIterations,
  );

  @override
  Uint8List newSalt([KdfParams? params]) =>
      randomBytes((params ?? portableParams).saltBytes);

  @override
  Future<DerivedKey> derive(
    String passphrase, {
    required Uint8List salt,
    required KdfParams params,
  }) async {
    if (params.algorithm != 'pbkdf2-hmac-sha256') {
      throw UnsupportedError('Pbkdf2KeyDerivation cannot run ${params.algorithm}');
    }
    if (params.iterations < 1) {
      throw ArgumentError.value(params.iterations, 'iterations', 'must be >= 1');
    }
    final bytes = pbkdf2(
      password: passphrase,
      salt: salt,
      iterations: params.iterations,
      keyLength: params.keyBytes,
    );
    return DerivedKey(bytes: bytes, params: params, salt: salt);
  }

  @override
  bool constantTimeEquals(List<int> a, List<int> b) {
    if (a.length != b.length) return false;
    var diff = 0;
    for (var i = 0; i < a.length; i++) {
      diff |= a[i] ^ b[i];
    }
    return diff == 0;
  }
}

/// PBKDF2-HMAC-SHA256, exposed as a free function so the vector tests can call
/// it directly.
Uint8List pbkdf2({
  required String password,
  required Uint8List salt,
  required int iterations,
  required int keyLength,
  bool utf8Password = true,
}) {
  final prf = HmacSha256(key: utf8Password ? utf8Encode(password) : _latin1(password));
  final blockCount = (keyLength + 31) ~/ 32;
  final output = Uint8List(blockCount * 32);

  final block = Uint8List(4);
  for (var i = 1; i <= blockCount; i++) {
    block[0] = (i >> 24) & 0xFF;
    block[1] = (i >> 16) & 0xFF;
    block[2] = (i >> 8) & 0xFF;
    block[3] = i & 0xFF;

    // U1 = PRF(password, salt ‖ INT_BE(i));  Uc = PRF(password, U(c-1))
    var u = prf.compute(_concat(salt, block));
    final accumulator = Uint8List.fromList(u);
    for (var c = 1; c < iterations; c++) {
      u = prf.compute(u);
      for (var k = 0; k < 32; k++) {
        accumulator[k] ^= u[k];
      }
    }
    output.setRange((i - 1) * 32, i * 32, accumulator);
  }
  return Uint8List.sublistView(output, 0, keyLength);
}

Uint8List _latin1(String value) {
  final out = Uint8List(value.length);
  for (var i = 0; i < value.length; i++) {
    out[i] = value.codeUnitAt(i) & 0xFF;
  }
  return out;
}

Uint8List _concat(List<int> a, List<int> b) {
  final out = Uint8List(a.length + b.length)
    ..setRange(0, a.length, a)
    ..setRange(a.length, a.length + b.length, b);
  return out;
}

/// HKDF-SHA256 (RFC 5869) — how one master key becomes several independent
/// keys: the database key, the attachment-vault key and the backup-pack key
/// are three HKDF expansions of the same DEK with different `info` strings.
/// That is why compromising a backup pack cannot decrypt the live database.
/// `info` is raw BYTES, not a string: RFC 5869 treats it as opaque context
/// data, and round-tripping it through UTF-8 would silently change any info
/// value that is not ASCII. (This was caught by the RFC vectors — a String
/// parameter mangled the 0xf0…f9 info of test case 1.) Callers with a human
/// label use [deriveSubkey], which encodes it.
Uint8List hkdfSha256({
  required Uint8List ikm,
  required List<int> info,
  Uint8List? salt,
  int length = 32,
}) {
  // RFC 5869 §2.2: an absent salt is HashLen zero bytes. (An explicitly empty
  // salt hashes identically, because HMAC pads any key below the block size
  // with zeros — so this is a clarity choice, not a behavioural one.)
  final actualSalt = salt ?? Uint8List(32);
  final prk = HmacSha256(key: actualSalt).compute(ikm);

  final output = Uint8List(length);
  var previous = const <int>[];
  var offset = 0;
  var counter = 1;
  while (offset < length) {
    final input = _concat(_concat(previous, info), [counter]);
    previous = HmacSha256(key: prk).compute(input);
    final take = (length - offset) < previous.length ? (length - offset) : previous.length;
    output.setRange(offset, offset + take, previous);
    offset += take;
    counter++;
  }
  return output;
}

/// never be accidentally swapped.
enum KeyPurpose {
  database('khata-pro/db/v1'),
  attachments('khata-pro/vault/v1'),
  backupPacks('khata-pro/backup/v1'),
  peerIdentity('khata-pro/peer-ed25519/v1');

  const KeyPurpose(this.info);
  final String info;
}

/// KhataPro · authenticated key wrapping.
///
/// The data encryption key (DEK) never exists on disk in the clear. It is
/// wrapped by a key-encryption key (KEK) that lives in the platform keystore
/// (Android Keystore / iOS Secure Enclave, when available) or is derived from
/// the user's passphrase (the no-hardware case). This file defines the wrap
/// FORMAT and the software implementation of it.
///
/// Construction: **AES-256-CTR + HMAC-SHA256, encrypt-then-MAC.** The MAC is
/// computed over the envelope header *and* the ciphertext *and* the caller's
/// associated data, and is verified before a single byte is decrypted. That
/// ordering matters: decrypt-then-verify hands an attacker a decryption oracle
/// and is the classic way AEAD gets broken in practice.
///
/// Why not AES-GCM here? On Android and iOS the *platform* performs the wrap
/// (Keystore `AES/GCM/NoPadding`, CryptoKit `AES.GCM`), and this app records
/// `wrap_algo = 'aes-256-gcm+keystore'` and lets the platform do it. The
/// software path exists for: devices with no usable keystore, the passphrase
/// custody level, backup packs, and every non-Flutter tool (restore CLI, the
/// verification harness). It is written to the same interface so the two are
/// interchangeable and testable together.
library;

import 'dart:typed_data';

import 'aes.dart';
import 'hasher.dart';
import 'kdf.dart';

/// How a key was wrapped. Stored verbatim in `key_material.wrap_algo`, so a
/// build released later can always tell how to unwrap what an older build
/// wrote — the difference between "your backup restores" and "your backup is
/// a blob".

  /// a raw key derived from `Keystore.getKey()`).

  aes256GcmPlatform('aes-256-gcm+keystore'),

  /// The software path defined in this file.
  aes256CtrHmac('aes256-ctr-hmac-sha256'),

  /// AES-256-GCM in pure software, for platforms whose native crypto we do not
  /// link. Kept in the enum so a future revision can populate it without a
  /// format break.
  aes256GcmSoftware('aes-256-gcm');

  const KeyWrapAlgorithm(this.id);

  /// The exact string stored in `key_material.wrap_algo`.
  final String id;

  /// wrapped key can never be replayed as a wrapped *backup* or a wrapped
  /// attachment key.

  final int version;
  final KeyWrapAlgorithm algorithm;

  /// `key_material.key_id` — the row this envelope belongs to.

        '${KeyWrapAlgorithm.aes256CtrHmac.id}',

    if (envelope.nonce.length != 16) {

    return plaintext;
  }
}

/// HMAC-SHA256 (RFC 2104), reusable across many messages — which is what makes
/// PBKDF2's millions of invocations tolerable: the key pads are hashed once.
final class HmacSha256 {
  HmacSha256({required List<int> key}) {
    var actualKey = Uint8List.fromList(key);
    if (actualKey.length > 64) actualKey = sha256(actualKey);
    final padded = Uint8List(64)..setRange(0, actualKey.length, actualKey);
    _innerPad = Uint8List(64);
    _outerPad = Uint8List(64);
    for (var i = 0; i < 64; i++) {
      _innerPad[i] = padded[i] ^ 0x36;
      _outerPad[i] = padded[i] ^ 0x5c;
    }
  }

  late final Uint8List _innerPad;
  late final Uint8List _outerPad;

  Uint8List compute(List<int> message) {
    final innerDigest = (Sha256()
          ..update(_innerPad)
          ..update(message))
        .digest();
    return (Sha256()
          ..update(_outerPad)
          ..update(innerDigest))
        .digest();
  }

  /// Streaming variant for large messages (attachments, backup packs).
  Uint8List computeStreaming(Iterable<List<int>> chunks) {
    final inner = Sha256()..update(_innerPad);
    for (final chunk in chunks) {
      inner.update(chunk);
    }
    return (Sha256()
          ..update(_outerPad)
          ..update(inner.digest()))
        .digest();
  }
}

/// Deliberately strict: lone surrogates are rejected rather than silently
/// replaced, because a mangled passphrase would derive a key that cannot be
/// reproduced on another platform — i.e. an unlocked vault that is permanently
/// unreadable.
Uint8List utf8Encode(String value) {
  final out = Uint8List(4 * value.length);
  var length = 0;
  for (var i = 0; i < value.length; i++) {
    var codePoint = value.codeUnitAt(i);
    if (codePoint >= 0xD800 && codePoint <= 0xDBFF) {
      if (i + 1 >= value.length) {
        throw ArgumentError('utf8Encode: lone high surrogate at index $i');
      }
      final low = value.codeUnitAt(i + 1);
      if (low < 0xDC00 || low > 0xDFFF) {
        throw ArgumentError('utf8Encode: unpaired high surrogate at index $i');
      }
      codePoint = 0x10000 + ((codePoint - 0xD800) << 10) + (low - 0xDC00);
      i++;
    } else if (codePoint >= 0xDC00 && codePoint <= 0xDFFF) {
      throw ArgumentError('utf8Encode: lone low surrogate at index $i');
    }

    if (codePoint < 0x80) {
      out[length++] = codePoint;
    } else if (codePoint < 0x800) {
      out[length++] = 0xC0 | (codePoint >> 6);
      out[length++] = 0x80 | (codePoint & 0x3F);
    } else if (codePoint < 0x10000) {
      out[length++] = 0xE0 | (codePoint >> 12);
      out[length++] = 0x80 | ((codePoint >> 6) & 0x3F);
      out[length++] = 0x80 | (codePoint & 0x3F);
    } else {
      out[length++] = 0xF0 | (codePoint >> 18);
      out[length++] = 0x80 | ((codePoint >> 12) & 0x3F);
      out[length++] = 0x80 | ((codePoint >> 6) & 0x3F);
      out[length++] = 0x80 | (codePoint & 0x3F);
    }
  }
  return Uint8List.sublistView(out, 0, length);

/// KhataPro · AES-256 (encrypt direction only) and CTS-free CTR mode.
///
/// Why hand-written: the key-wrapping codec must run in three environments —
/// inside Flutter on device, inside the bare-Dart verification harness, and
/// inside a future CLI restore tool that must decrypt a backup pack on a
/// machine with no Flutter installed. A pure implementation with no package
/// dependency is the only way all three work from one source.
///
/// Why encrypt-only: [AesCtr] is all this app needs, and CTR mode uses only the
/// forward cipher. That removes the inverse cipher, the inverse S-box, and the
/// InvMixColumns tables — roughly half the code, and the half where bugs hide.
///
/// Verification: `tool/aes_verify.dart` checks the FIPS-197 known-answer vectors
/// and a differential set generated by OpenSSL 3 (an independent
/// implementation). A wrong S-box produces output that looks random and
/// decrypts correctly *by itself*, so nothing in the app would ever notice —
/// only an external oracle catches that class of bug.
library;

import 'dart:typed_data';

/// AES-256 block cipher, encryption direction.
final class Aes256 {
  Aes256(List<int> key)
      : assert(key.length == 32, 'AES-256 needs a 32-byte key'),
        _roundKeys = _expandKey(key);

  static const int keySize = 32;
  static const int _rounds = 14; // Nr for AES-256

  /// 15 round keys × 16 bytes, flattened (60 words).
  final Uint8List _roundKeys;

  /// Encrypts exactly one 16-byte block in place.
  void encryptBlock(Uint8List block, [int offset = 0]) {
    assert(block.length - offset >= 16, 'need a full block');
    final state = Uint8List(16);
    for (var i = 0; i < 16; i++) {
      state[i] = block[offset + i] ^ _roundKeys[i];
    }

    for (var round = 1; round < _rounds; round++) {
      _subBytes(state);
      _shiftRows(state);
      _mixColumns(state);
      _addRoundKey(state, round);
    }
    // Final round: no MixColumns.
    _subBytes(state);
    _shiftRows(state);
    _addRoundKey(state, _rounds);

    for (var i = 0; i < 16; i++) {
      block[offset + i] = state[i];
    }
  }

  void _addRoundKey(Uint8List state, int round) {
    final base = round * 16;
    for (var i = 0; i < 16; i++) {
      state[i] ^= _roundKeys[base + i];
    }
  }

  static void _subBytes(Uint8List state) {
    for (var i = 0; i < 16; i++) {
      state[i] = sBox[state[i]];
    }
  }

  /// The AES state is column-major: byte `4*c + r` is row r of column c.
  /// ShiftRows rotates row r left by r positions.
  static void _shiftRows(Uint8List s) {
    final t = Uint8List.fromList(s);
    for (var row = 1; row < 4; row++) {
      for (var col = 0; col < 4; col++) {
        s[4 * col + row] = t[4 * ((col + row) % 4) + row];
      }
    }
  }

  static void _mixColumns(Uint8List s) {
    for (var col = 0; col < 4; col++) {
      final i = col * 4;
      final a0 = s[i], a1 = s[i + 1], a2 = s[i + 2], a3 = s[i + 3];
      s[i] = _xtime(a0) ^ (_xtime(a1) ^ a1) ^ a2 ^ a3;
      s[i + 1] = a0 ^ _xtime(a1) ^ (_xtime(a2) ^ a2) ^ a3;
      s[i + 2] = a0 ^ a1 ^ _xtime(a2) ^ (_xtime(a3) ^ a3);
      s[i + 3] = (_xtime(a0) ^ a0) ^ a1 ^ a2 ^ _xtime(a3);
    }
  }

  static int _xtime(int value) {
    final shifted = (value << 1) & 0xFF;
    return (value & 0x80) != 0 ? shifted ^ 0x1B : shifted;

    final w = Uint8List(words * 4);

      w[i] = key[i];
    }

    var rcon = 1;
    for (var i = nk; i < words; i++) {
      final base = i * 4;
      final previous = (i - 1) * 4;
      if (i % nk == 0) {
        // RotWord + SubWord + Rcon
        w[base] = sBox[w[previous + 1]] ^ rcon;
        w[base + 1] = sBox[w[previous + 2]];
        w[base + 2] = sBox[w[previous + 3]];
        w[base + 3] = sBox[w[previous]];
        rcon = _xtime(rcon);
      } else if (i % nk == 4) {
        // AES-256 only: an extra SubWord in the middle of the eight-word run.
        for (var k = 0; k < 4; k++) {
          w[base + k] = sBox[w[previous + k]];
        }
      } else {
        for (var k = 0; k < 4; k++) {
          w[base + k] = w[previous + k];
        }
      }
      for (var k = 0; k < 4; k++) {
        w[base + k] ^= w[base - nk * 4 + k];
      }
    }
    return w;
  }

  /// The S-box, built from its definition rather than copied from a table:
  /// `S(a) = affine(a⁻¹ in GF(2⁸))`. Generated once, lazily.
  static final Uint8List sBox = _buildSBox();

  static Uint8List _buildSBox() {
    final inverse = Uint8List(256);
    for (var i = 1; i < 256; i++) {
      inverse[i] = _gfInverse(i);
    }
    inverse[0] = 0; // 0 has no inverse; S(0) = 0x63 by the affine map alone

    final box = Uint8List(256);
    for (var i = 0; i < 256; i++) {
      final x = inverse[i];
      // Affine transform: b ^= rotl(b, 1..4), then XOR 0x63.
      final y = x ^ _rotl8(x, 1) ^ _rotl8(x, 2) ^ _rotl8(x, 3) ^ _rotl8(x, 4) ^ 0x63;
      box[i] = y & 0xFF;
    }
    return box;
  }

  static int _rotl8(int value, int bits) =>
      ((value << bits) | (value >> (8 - bits))) & 0xFF;

  /// Multiplicative inverse in GF(2⁸) by square-and-multiply (a²⁵⁴ = a⁻¹).
  static int _gfInverse(int a) {
    var result = 1;
    var base = a;
    var exponent = 254;
    while (exponent > 0) {
      if ((exponent & 1) != 0) result = _gfMultiply(result, base);
      base = _gfMultiply(base, base);
      exponent >>= 1;
    }
    return result;
  }

  static int _gfMultiply(int a, int b) {
    var result = 0;
    var x = a;
    var y = b;
    while (y > 0) {
      if ((y & 1) != 0) result ^= x;
      x = _xtime(x);
      y >>= 1;
    }
    return result & 0xFF;
  }
}

/// AES-256 in counter mode.
///
/// The counter is the full 128-bit big-endian block, incremented as an integer
/// — the same convention as OpenSSL's `aes-256-ctr` and NIST SP 800-38A, so the
/// differential vectors apply directly.
///
/// **CTR provides confidentiality only.** It is never used alone here: callers
/// use [AesCtrHmac], which is encrypt-then-MAC and therefore authenticated.
final class AesCtr {
  AesCtr({required List<int> key, required List<int> iv})
      : assert(iv.length == 16, 'CTR IV must be 16 bytes'),
        _cipher = Aes256(key),
        _counter = Uint8List.fromList(iv);

  final Aes256 _cipher;
  final Uint8List _counter;
  final Uint8List _keystream = Uint8List(Aes256.blockSize);
  int _keystreamOffset = Aes256.blockSize; // forces a refill on first use

  /// XORs [length] bytes of keystream into `data[offset..]`. Symmetric: the
  /// same call encrypts and decrypts.
  void apply(Uint8List data) {
    for (var i = 0; i < data.length; i++) {
      if (_keystreamOffset == Aes256.blockSize) {
        // Copy the counter, THEN encrypt the copy. Encrypting `_counter` in
        // place would overwrite the counter with its own ciphertext, so every
        // block after the first would use a nonsense counter — a bug that
        // survives every self-consistency test and is only visible against an
        // external reference. (Caught by tool/aes_verify.dart.)
        _keystream.setAll(0, _counter);
        _cipher.encryptBlock(_keystream);
        _incrementCounter();
        _keystreamOffset = 0;
      }
      data[i] ^= _keystream[_keystreamOffset++];
    }
  }

  void _incrementCounter() {
    for (var i = 15; i >= 0; i--) {
      _counter[i] = (_counter[i] + 1) & 0xFF;
      if (_counter[i] != 0) return;
    }
    // Counter wrapped: 2¹²⁸ blocks. Unreachable in practice (an exabyte), and
    // silently reusing keystream would be catastrophic — so refuse instead.
    throw StateError('AES-CTR counter exhausted');
  }
}

/// KhataPro · the merge contract.
///
/// "Bulletproof LWW" is the acceptance criterion for this layer, and it decomposes
/// into properties that can be *executed* rather than asserted in prose. A
/// two-phone shop is the running example: the counter phone and the back-office
/// phone, both offline, both editing the same customer.
///
/// What is proven here, in order:
///
///   1. **Deterministic** — the same two versions always pick the same winner.
///   2. **Commutative** — A-then-B and B-then-A converge to the same row.
///   3. **Idempotent** — replaying a batch changes nothing (peers re-send freely).
///   4. **Lossless in the honest sense** — the losing *value* is never discarded
///      silently; it is handed back as a `FieldConflict` for `conflict_log`.
///   5. **Tombstones are writes too** — an old delete cannot kill a newer edit.
///   6. **No guessing** — the two situations the rules cannot decide become
///      blocking anomalies instead of a coin flip.
///
